### 2. 关键技术沉淀

- **注入式确定性规划器**：生产用 LLM 规划，测试注入 `DeterministicPlanner`（固定动作序列），只测"执行链路"，不依赖真实模型
- **记忆系统**：`Memory` 类（写/检索/遗忘/clear + 容量上限），满容量抛 `MemoryFull`
- **轨迹重放**：`agent.replay(trajectory)` 重新执行轨迹验证可复现性
- **质量门模式**：`CompositeScore` 封装 `score()` 和 `is_pass()`，阈值 0.6 卡质量
- **TDD 实测**：每个模块先写测试、跑通再 commit，不靠"应该没问题"

### 3. 卡点与解决

| 卡点 | 解决 |
|---|---|
| 工具缺参数时抛什么错 | 用 `pytest.raises((KeyError, TypeError))` 兜底缺失参数和类型错误 |
| 记忆满时该抛错还是覆盖 | 确定策略：超容量抛 `MemoryFull`，覆盖已存在键不算新写入 |
| 多轮记忆状态不串 | 每个 run 独立 trajectory，状态不跨任务累积 |
| 确定性规划器序列耗尽 | 用 `raise StopIteration` 通知终止，不抛异常 |
