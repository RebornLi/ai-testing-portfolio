### 2. 关键技术沉淀

- **注入式确定性替身**：生产用 LLM 的规划能力，测试注入 `DeterministicPlanner`（固定动作序列）/ `LoopingPlanner`（失控循环测终止）。这样测试不依赖真实模型，只测"执行链路"。
- **记忆系统**：`Memory` 类（写/检索/遗忘/clear + 容量上限，满抛 `MemoryFull`），可驱动 Agent 行为。
- **轨迹重放**：`agent.replay(trajectory)` 重新执行轨迹验证可复现性。
- **终止三态**：`reason="stopped"` / `"sequence_end"` / `"max_iterations"`（硬上限防死循环）。
- **多智能体编排**：`Orchestrator`（按 routing 分发）+ `SequentialOrchestrator`（顺序执行，遇未知 Agent 记 `unknown_agent`）+ `MockSubAgent`（确定性子 Agent 替身，绕开真实 LLM）。
- **TDD 实测**：每个模块先写测试、跑通再 commit，不靠"应该没问题"。

### 3. 卡点与解决

| 卡点 | 解决 |
|---|---|
| 工具缺参数时抛什么错 | 用 `pytest.raises((KeyError, TypeError))` 兜底缺失参数和类型错误 |
| 记忆满时该抛错还是覆盖 | 确定策略：超容量抛 `MemoryFull`，覆盖已存在键不算新写入 |
| 编排遇未知子 Agent 该中断还是跳过 | 本实现跳过并记 `unknown_agent`，不中断整条链 |
| 确定性规划器序列耗尽 | 用 `raise StopIteration` 通知终止，run() 捕获 |
