> 验收：`agent-lab/` 独立工程 + pytest 65 用例全绿 + 里程碑复盘 + commit

## 🎯 本周总目标

阶段「AI 应用评测」的 **Agent 层**。Agent = LLM + 工具 + 循环 + 记忆，比 RAG 多四件事：**有状态会话、工具调用断言、ReAct 轨迹、循环终止性**，再加多智能体编排。

本周核心思想（贯穿全程）：

> **真实 Agent 的「决策」来自 LLM，测试不能依赖模型 → 注入「确定性替身」（确定性规划器 / 确定性子 Agent）**，只测「执行链路」，做到离线、确定、可复现。

五个评测维度（逐日递进）：
1. **工具正确性 + 终止 / 轨迹 / 状态**（D1）
2. **工具调用链**：name/args/result/顺序 + 轨迹重放（D2）
3. **多工具协作 + 错误断言**（D3）
4. **记忆系统**：写 / 检索 / 遗忘 / 容量（D4）
5. **多智能体编排**：分发 / 汇总 / 顺序（D6）

## 📅 每日任务

### D1（08-26）ReAct Agent 核心 ★
- 学习：Agent 测试 vs 普通测试（有状态 / 轨迹 / 循环）；ReAct = Reasoning + Acting 循环；为什么难测
- 实战：工具集 `tools.py`（确定性纯函数）+ `ReActAgent` + 注入式确定性规划器
- 产出：`agent/tools.py` / `agent.py`（ReActAgent 骨架）
- 验收：工具正确性 + 终止 + 轨迹 + 状态（工具 10 + 核心 12 用例）

### D2（08-27）工具调用链 + 全流程 ★ 今日重点
- 学习：Agent 轨迹自包含（`[{name, args, result}, ...]`）；链式断言 4 关注点
- 实战：工具调用链断言（args 匹配 / 结果正确 / 顺序 / 次数）；补 `replay()` 轨迹重放能力
- 产出：`test_agent_chain.py`
- 验收：10 用例全绿（含补 `agent.replay()` 修真 bug）

### D3（08-28）多工具协作 + 错误断言 ★
- 学习：协作链（前一步输出 = 后一步输入）；工具错误类型（缺失 / 类型 / 未知工具）
- 实战：`test_agent_collab.py`（协作链 + 4 类错误断言）；`pytest.raises` 兜底
- 产出：协作链测试 + 错误断言
- 验收：10 用例全绿（agent-lab 累计 42）

### D4（08-29）全流程 + 记忆系统 ★
- 学习：记忆是什么（写 / 检索 / 遗忘 / 容量）；记忆如何影响多轮决策
- 实战：`agent.py` 加 `Memory` 类（满抛 `MemoryFull`）+ `test_agent_memory.py`
- 产出：记忆系统 + 记忆驱动行为测试
- 验收：10 用例全绿（agent-lab 累计 52）

### D5（08-30）本周技术复盘
- 任务：回顾 D1-D4 交付，梳理技术沉淀（注入式规划器 / 记忆 / 轨迹重放 / 质量门 / TDD）
- 产出：本周技术复盘记录
- 验收：全量测试验证 + 复盘

> 注：D5 与 D6 同天（周六）。D5 做技术梳理，D6 补齐多智能体编排。

- 实战：`orchestrator.py`（Orchestrator + SequentialOrchestrator + MockSubAgent）+ 分发 / 汇总 / 顺序 / 未知 Agent 断言
