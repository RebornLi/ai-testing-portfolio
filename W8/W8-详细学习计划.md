## 🎯 本周总目标（对标整体规划 W8）

阶段二「AI 核心」第 8 周，从"会造 Agent / 会评测"进阶到"会安全地评测 Agent"——
AI 安全岗 / 安全测试的核心竞争力。这一周要把 W7 那套"一键评测"的框架，
改造成"一审计就把 agent 的安全隐患揪出来"的安全审计：

1. **提示注入（Prompt Injection）**：攻击者藏指令，agent 会不会照做？
2. **权限边界（Permission）**：低权限用户能不能拿到高机密？
3. **敏感信息泄露（Data Exfiltration）**：agent 会不会明文吐出不该吐的东西？
4. **安全审计工程化**：pytest + 确定性规则，能复现地证明"这个 agent 不安全"。

> ⚠️ 本周要动手搭 `security-lab/`——不是纸上谈兵，要能跑出分数、能进 CI。

## 📅 每日任务

### D1（09-10 周四）：安全测试基础 — 三类攻击与三个维度 ★
- 学习：提示注入是什么（直接 / 间接），越权 / 泄露怎么形成
- 实战：手算一个带"系统提示 + 用户攻击"的 agent 会怎么中招
- 产出：概念笔记① 安全三维度表 + 一句话笔记
- 验收：能讲清"怎么评价一个 Agent 是否安全"

### D2（09-11 周五）：提示注入攻击测试 ★
- 学习：怎么断言"agent 没中招"——injected 标志、指令被拒绝
- 实战：给确定性 agent 写一组注入攻击语料，写断言用例
- 产出：注入审计用例集 + 测试报告
- 验收：能写出 3 条"注入是否被照做"的断言

### D3（09-12 周六）：权限越权测试 ★
- 学习：最小权限原则、角色分层、越权怎么绕过
- 实战：设计"user 想拿 admin 机密"的场景，测 agent 是否放行
- 产出：越权评测脚本（双路断言：越权要拒 + 合法放行）
- 验收：能设计"越权应该被拒"的用例并抓住它

### D4（09-13 周日）：敏感信息泄露测试 ★
- 学习：agent 把内部信息原样吐出算泄露，怎么拦截
- 实战：测 agent 在压力下是否明文泄露数据（含脱敏）
- 产出：泄露评测脚本（含输出脱敏检查）
- 验收：能设计"agent 泄露了"的用例并检测出来

### D5（09-14 周一）：安全审计工程化 — 进 CI ★
- 学习：把"审计"封装成一键脚本 + pytest 门禁
- 实战：跑两个 agent（漏洞版 vs 安全版），对比打分
- 产出：一键安全审计脚本 + Dockerfile + README
- 验收：`docker compose run` 一键跑通，进 GitHub Actions

### D6-D7（待定）：巩固复盘
- 任务：写 W8 一周总结 + 一页纸速记
- 复盘：本周最佳收获 + 下周重点
