## 二、一键入口 `run_evaluation.py`（1.5h）★ 核心

```python
"""run_evaluation.py — CLI 一键入口：跑安全审计 + 写报告。

用法：
    python run_evaluation.py            # 跑审计，打印报告，写 reports/
    python run_evaluation.py --json     # 额外打印 JSON 报告
    python run_evaluation.py --dir out  # 报告输出目录
"""
import sys, os, argparse
sys.path.insert(0, os.path.join(os.path.dirname(__file__), ".."))

from evaluate import run_security_audit
from reports.report import SecurityReport


def main():
    parser = argparse.ArgumentParser(description="安全审计流水线（三维度）")
    parser.add_argument("--json", action="store_true")
    parser.add_argument("--dir", default="reports")
    args = parser.parse_args()

    report = run_security_audit()
    print(report.to_text())
    json_path, txt_path = report.write(args.dir)

    # 退出码：安全达标 → 0，否则 1（供 CI 门禁）
    return 0 if report.passed else 1


if __name__ == "__main__":
    sys.exit(main())
```

> 设计要点：
> 1. 引擎 `evaluate.py` 只管"执行 + 打分"，CLI 只管"打印 + 写文件 + 退出码"——分离以便测试断言。
> 2. **退出码就是 CI 门禁**：0 = 安全达标放行，非 0 = 拦截合并。

## 三、Docker 离线镜像（2h）★ 产出

> 关键约束：**容器内无网络**，pip/apt 任何联网操作必败。
> 方案：用宿主机预拉好的 `wheels/`（与 W7 auto-eval 同款 pytest wheels），
> 镜像内 `--no-index --find-links` 离线安装。

```dockerfile
# W8 安全测试流水线 — 离线确定性审计镜像
FROM python:3.12-slim

ENV PYTHONUNBUFFERED=1 PYTHONDONTWRITEBYTECODE=1

WORKDIR /app

# 把预拉好的 wheel 一并打进镜像
COPY wheels/ /app/wheels/

# 离线安装依赖（--no-index 禁止联网，只从本地 wheels 取）
COPY requirements.txt .
RUN pip install --no-cache-dir --no-index --find-links=/app/wheels -r requirements.txt

# 复制安全审计代码
COPY . .

# 默认：跑全量安全测试（CI 门禁）
CMD ["pytest", "tests/", "-q"]
```
