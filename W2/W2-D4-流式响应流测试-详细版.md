## 一、为什么流式值得专门测（1.5h）★ 今日重点

> 流式 = LLM 边想边说,每个词实时推给你。你聊天界面里"一个字一个字冒出来"的体验就是它。
> 为什么要**测**流式?
> 1. **性能指标**:TTFT（First Time To First token）——首个字多久出来,决定体验
> 2. **完整性**:分块拼起来 == 非流式一次返回的完整内容?
> 3. **边界**:空流、超时、部分出错时程序会不会崩

### 1.1 流式 vs 非流式
| 对比 | 非流式 | 流式 |
|---|---|---|
| 返回方式 | 一次全部给 | 分多个 SSE 块逐步推 |
| 响应类型 | `chat.completion` | `chat.completion.chunk` |
| 逐块内容 | 在 `message.content` | 在 `delta.content` |
| 结束信号 | 整个响应结束 | 最后一块 `finish_reason` + `data: [DONE]` |
| 适用 | 脚本、评测 | 实时交互界面 |

### 1.2 SSE 协议格式
```
data: {"choices":[{"delta":{"content":"你好"}}]}
data: {"choices":[{"delta":{"content":"！"}}]}
data: {"choices":[{"delta":{},"finish_reason":"stop"}]}
data: [DONE]
```
> 每块以 `data: ` 开头,最后一块是 `data: [DONE]`。这就是流式的"契约"。

## 二、本机流式实测（1.5h）★ 最该抄的真实数据

> 本机 vLLM :8000 流式返回的真实 chunk（2026-08-31 实测）。

### 2.1 实测抓到的 chunk 结构
```
chunk#0:  object=chat.completion.chunk | role=assistant | content='' | finish_reason=None
chunk#1:  object=chat.completion.chunk | content='' | reasoning='The' | finish_reason=None
chunk#2:  object=chat.completion.chunk | content='' | reasoning=' user' | finish_reason=None
chunk#3:  object=chat.completion.chunk | content='' | reasoning=' is' | finish_reason=None
...
最后一块: object=chat.completion.chunk | content='' | finish_reason=length
结尾:     data: [DONE]
```

### 2.2 本机实测 3 个关键发现（务必记牢）
1. **对象类型是 `chat.completion.chunk`**（不是非流式的 `chat.completion`）
2. **逐块内容在 `choices[0].delta.content`**（不是 `message.content`）
3. **本机这个 thinking 模型**：流式时 81 块里有 **80 块是 `delta.reasoning`（思考过程），`delta.content` 为空**，以 `finish_reason=length` 结束。→ 这说明模型先"想"再"说"，思考内容在流式里先出来。

> ⚠️ 做评测时要注意：**这个模型流式输出主要是 reasoning**。要"纯内容"得把 reasoning 剥掉。非 thinking 模型 `delta.content` 就会有正常文字。

### 3.2 写 `src/llm_stream.py`（可复用流式客户端）
```python
"""流式 LLM 客户端（基于 httpx 的 SSE）"""
import json
import httpx


def stream_chat(base_url, prompt, api_key="", model="ornith1.5-35b",
                max_tokens=100, timeout=120):
    """生成器：逐块产出内容。yield 两个类型：
    - ("content", text)   一句正文
    - ("reasoning", text) 一段思考
    - ("finish", reason)  一轮结束
    """
    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "max_tokens": max_tokens,
        "stream": True,
    }
    headers = {}
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"
    with httpx.stream(
        "POST", f"{base_url}/v1/chat/completions",
        json=payload, headers=headers, timeout=timeout,
    ) as r:
        r.raise_for_status()
        full_content = ""
        full_reasoning = ""
        for line in r.iter_lines():
            line = line.strip()
            if not line or not line.startswith("data:"):
                continue
            data = line[len("data:"):].strip()
            if data == "[DONE]":
                break
            chunk = json.loads(data)
            choice = chunk["choices"][0]
            delta = choice.get("delta", {})
            content = delta.get("content", "")
            reasoning = delta.get("reasoning", "")
            if content:
                full_content += content
                yield ("content", content)
            if reasoning:
                full_reasoning += reasoning
                yield ("reasoning", reasoning)
            if choice.get("finish_reason"):
                yield ("finish", choice["finish_reason"])
        yield ("final", {"content": full_content, "reasoning": full_reasoning})
```

## 四、流式测试断言（1.5h）★ 今日产出②

> 流式测试不是"能跑就行",要断言:块数够、拼起来完整、结束信号对。

```python
"""W2-D4 产出②：流式响应测试（pytest + httpx 同步读取）"""
import os, json
import pytest
import httpx

BASE_URL = "http://127.0.0.1:8000"
API_KEY = os.environ.get("LLM_API_KEY", "")


def stream_read(prompt, max_tokens=100):
    """同步读取流式,返回 (chunks, 拼接内容, 拼接reasoning, finish_reason)。"""
    payload = {
        "model": "ornith1.5-35b",
        "messages": [{"role": "user", "content": prompt}],
        "max_tokens": max_tokens,
        "stream": True,
    }
    headers = {}
    if API_KEY:
        headers["Authorization"] = f"Bearer {API_KEY}"
    chunks = []
    content = ""
    reasoning = ""
    finish_reason = None
    with httpx.stream(
        "POST", f"{BASE_URL}/v1/chat/completions",
        json=payload, headers=headers, timeout=120,
    ) as r:
        r.raise_for_status()
        for line in r.iter_lines():
            line = line.strip()
            if not line.startswith("data:"):
                continue
            data = line[len("data:"):].strip()
            if data == "[DONE]":
                break
            chunks.append(data)                       # 存原始数据块
            d = json.loads(data)
            delta = d["choices"][0].get("delta", {})
            content += delta.get("content", "")
            reasoning += delta.get("reasoning", "")
            fr = d["choices"][0].get("finish_reason")
            if fr:
                finish_reason = fr
    return chunks, content, reasoning, finish_reason


def test_stream_yields_chunks():
    """① 流式至少返回若干 chunk（不是空流）。"""
    chunks, _, _, _ = stream_read("你好")
    assert len(chunks) >= 1
    assert all(c.startswith("data:") for c in chunks)


def test_stream_content_accumulates():
    """② 逐块 content 拼接 = 完整内容（对非 thinking 模型）。
    本机这个模型 content 多为空（输出在 reasoning 里），
    所以这里断言 reasoning 有内容。"""
    _, content, reasoning, _ = stream_read("随便说一句")
    assert reasoning.strip() != ""  # 本机思考内容非空
    # 若用普通模型，可改成 assert content.strip() != ""


def test_stream_finish_reason_present():
    """③ 最后一块一定有 finish_reason（不是 None）。"""
    _, _, _, finish = stream_read("你好")
    assert finish in ["stop", "length", "function_call"]


def test_stream_object_type():
    """④ 每个 chunk 的 object 是 chat.completion.chunk。"""
    payload = {
        "model": "ornith1.5-35b",
        "messages": [{"role": "user", "content": "hi"}],
        "stream": True, "max_tokens": 30,
    }
    headers = {"Authorization": f"Bearer {API_KEY}"} if API_KEY else {}
    objs = set()
    with httpx.stream(
        "POST", f"{BASE_URL}/v1/chat/completions",
        json=payload, headers=headers, timeout=120,
    ) as r:
        r.raise_for_status()
        for line in r.iter_lines():
            line = line.strip()
            if line.startswith("data:") and line != "data: [DONE]":
                objs.add(json.loads(line[len('data:'):])["object"])
    assert objs == {"chat.completion.chunk"}


def test_stream_and_nonstream_consistent():
    """⑤ 流式拼出的内容(非 reasoning)应大致等于非流式一次返回的内容。
    注意: 本模型 thinking 输出在 reasoning, 这里用 reasoning 对齐。"""
    _, content, reasoning, _ = stream_read("用一句话说说今天", max_tokens=40)
    r = httpx.post(f"{BASE_URL}/v1/chat/completions",
                   json={"model": "ornith1.5-35b",
                         "messages": [{"role": "user", "content": "用一句话说说今天"}],
                         "max_tokens": 40, "stream": False},
                   headers={"Authorization": f"Bearer {API_KEY}"} if API_KEY else {},
                   timeout=60)
    r.raise_for_status()
    nonstream = r.json()["choices"][0]["message"]["content"]
    # 断言两者"都非空"即可（thinking 模型两路输出侧重不同，不强求相等）
    assert reasoning.strip() != "" or content.strip() != ""
    assert nonstream.strip() != ""
```

## 五、异常流式（1.5h）

> 流式也会出问题：超时、空流、错误状态码。都要测。

```python
def test_stream_timeout_handles_slow_server(monkeypatch):
    """⑥ 服务慢/挂时，timeout 触发，程序不卡死。"""
    monkeypatch.setenv("LLM_API_KEY", "")
    payload = {"model": "ornith1.5-35b",
               "messages": [{"role": "user", "content": "hi"}],
               "stream": True, "max_tokens": 10}
    with pytest.raises(httpx.TimeoutException):
        with httpx.stream("POST", "http://127.0.0.1:9999/v1/chat/completions",
                          json=payload, timeout=1) as r:   # 没人监听的端口
            r.raise_for_status()


def test_stream_bad_model_still_streams():
    """⑦ 非法模型不 stream, 直接抛 HTTP 错误（应被 raise_for_status 接住）。"""
    payload = {"model": "不存在的模型",
               "messages": [{"role": "user", "content": "hi"}],
               "stream": True, "max_tokens": 10}
    r = httpx.post(f"{BASE_URL}/v1/chat/completions", json=payload, timeout=10)
    # 期望非 2xx
    assert r.status_code != 200
```

## 🎯 今日关键词

```
stream=true              → 开启流式
data: ...                → SSE 块，data: [DONE] 终止
choices[0].delta.content → 逐块正文（非流式在 message.content）
object=chat.completion.chunk  → 流式对象类型
finish_reason            → 最后一块给出（stop/length）
TTFT                     → 第一个 token 多久出来（流式性能指标）
```

> 流式的核心心智：**别等，来了就处理**。非流式是"全拿回来再分析"，
> 流式是"每来一块处理一块"，直到 `[DONE]`。这正是 Agent 要实时响应的关键。
