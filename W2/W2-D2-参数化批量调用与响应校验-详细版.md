## 一、为什么 LLM 测试要参数化（1.5h）★ 今日重点

> 调用 LLM 是要花钱/花时间的。所以批量评测时要：
> 1. **参数化**：一个函数喂多组 prompt，每组都跑
> 2. **校验**：确认每个响应"都长对了"
> 3. **计量**：记录每次 token 用量（成本/性能是评测重点）

### 1.1 参数化 vs 手抄（对比）
```python
# ❌ 手抄：写死 prompt，重复 5 遍，全是重复代码
def test_prompt_1():
    resp = chat("任务1")
    assert resp["choices"][0]["message"]["content"]
def test_prompt_2():
    resp = chat("任务2")
    assert resp["choices"][0]["message"]["content"]
# ... 写 5 遍

# ✅ 参数化：一个列表搞定
@pytest.mark.parametrize("prompt", ["任务1", "任务2", "任务3", "任务4", "任务5"])
def test_batch(prompt):
    resp = chat(prompt)
    assert resp["choices"][0]["message"]["content"]
```

> 跑 `pytest -v` 会看到 **5 个独立用例**（每个 prompt 一个），而不是 1 个。这是 LLM 批量评测的标准姿势。

## 二、响应结构校验（1.5h）★ 今天最该理解的观念

> 不能只断言"内容非空"。要断言**整个响应结构都对了**——这才是工程化测试。

### 2.1 一次"合格"的 chat completion 要满足
```python
resp["object"] == "chat.completion"
len(resp["choices"]) == 1                 # 默认 1 条
resp["choices"][0]["message"]["role"] == "assistant"
resp["choices"][0]["message"]["content"].strip() != ""
resp["choices"][0]["finish_reason"] in ["stop", "length", "function_call"]
resp["usage"]["total_tokens"] > 0
```

### 2.2 为什么要校验 finish_reason？
- `"length"` → 可能被 max_tokens 截断（回答不完整，是个 bug 信号）
- `"stop"` → 自然结束
- 它能帮你发现"回答被截断"这类问题

> **本机实测**：当 `max_tokens` 太小时，`finish_reason` 会变 `length`。评测要能捕获它。

### 2.3 本机实测的几个坑（务必记牢）
| 现象 | 实测结果 | 怎么应对 |
|---|---|---|
| 本机模型叫啥 | `ornith1.5-35b`（不是 nemotron3） | 用真实模型名 |
| 是否返回 reasoning | **是**（有 `reasoning` 字段，约 71 字符） | 回答可能含"思考过程" |
| 回答开头 | 常有 `\n\n` 开头 | 断言时用 `strip()` 再比 |
| 不存在模型 | **404**，错误信息含 model 名 | `raise_for_status()` 自动抓 |
| 空 messages | **400**，报"empty conversation" | 见第七节异常测试 |
| 无 API key | **401** | 确认 key 已注入 |

## 三、实战：参数化调用 + 响应校验（2h）★ 今日产出①

> 承接 D1 的 `test_llm_basic.py`（chat 函数）。

### 3.1 写 `tests/test_llm_batch.py`
```python
"""W2-D2 产出①：参数化批量调用 + 结构校验（requests 版）"""
import os, json
import pytest
import requests

BASE_URL = "http://127.0.0.1:8000"
API_KEY = os.environ.get("LLM_API_KEY", "")


def chat(prompt, max_tokens=60, temperature=0.0):
    """调用 LLM 一次，返回完整响应字典。"""
    payload = {
        "model": "ornith1.5-35b",
        "messages": [{"role": "user", "content": prompt}],
        "max_tokens": max_tokens,
        "temperature": temperature,
    }
    headers = {}
    if API_KEY:
        headers["Authorization"] = f"Bearer {API_KEY}"
    r = requests.post(f"{BASE_URL}/v1/chat/completions",
                      json=payload, headers=headers, timeout=60)
    r.raise_for_status()
    return r.json()


def assert_valid_response(resp):
    """一个合格的 chat completion 响应该有的样子。"""
    assert resp["object"] == "chat.completion"
    assert len(resp["choices"]) == 1
    msg = resp["choices"][0]["message"]
    assert msg["role"] == "assistant"
    assert msg["content"].strip() != ""
    assert resp["choices"][0]["finish_reason"] in ["stop", "length", "function_call"]
    assert resp["usage"]["total_tokens"] > 0


# 参数化：5 组 prompt
@pytest.mark.parametrize("prompt", [
    "用一句话解释什么是人工智能",
    "北京今天天气怎么样",
    "python 中如何遍历一个字典？",
    "给我讲一个关于猫的笑话",
    "1+1 等于几？",
])
def test_batch_response_is_valid(prompt):
    """① 每组 prompt 的响应，结构都合格。"""
    assert_valid_response(chat(prompt))


def test_usage_tracked_per_call():
    """② 每次调用 usage.total_tokens 都是正数（成本可计量）。
    本机实测：max_tokens=60 时 completion≈60，total≈61~72。
    """
    for i in range(3):
        resp = chat(f"任务{i}", max_tokens=60)
        assert resp["usage"]["total_tokens"] > 0


def test_answer_content_is_string():
    """③ 答案正文是字符串，不是 None。"""
    resp = chat("你好")
    content = resp["choices"][0]["message"]["content"]
    assert isinstance(content, str)
    assert content.strip()  # 去空白后非空
```

## 四、结构化输出（1.5h）★ 产出②

> 让 LLM **只输出 JSON**，方便程序解析。用 `response_format` 参数。

### 4.1 本机实测结果
```bash
curl -H "Authorization: Bearer $KEY" \
  -H 'Content-Type: application/json' \
  -d '{"model":"ornith1.5-35b",
       "messages":[{"role":"user","content":"输出一段信息"}],
       "response_format":{"type":"json_object"},"max_tokens":80}' \
  http://127.0.0.1:8000/v1/chat/completions
# 本机实测返回 200，content 确实是 JSON：
#   {\n"content":"生活虽有波折，但每一步都在靠近想要的远方。保持'
```

> 结论：**本机 vLLM 支持 `response_format: json_object`**（返回 200 + JSON 正文）。

### 4.2 结构化输出测试
```python
def test_structured_json_output():
    """④ 要求 JSON 输出，内容能被 json.loads 解析。"""
    payload = {
        "model": "ornith1.5-35b",
        "messages": [{"role": "user", "content": "用 JSON 输出：{\"关键词\": \"测试\"}"}],
        "response_format": {"type": "json_object"},
        "max_tokens": 80,
    }
    headers = {"Authorization": f"Bearer {API_KEY}"} if API_KEY else {}
    r = requests.post(f"{BASE_URL}/v1/chat/completions",
                      json=payload, headers=headers, timeout=60)
    assert r.status_code == 200
    resp = r.json()
    content = resp["choices"][0]["message"]["content"].strip()
    parsed = json.loads(content)      # 能解析才算合格
    assert isinstance(parsed, dict)


def test_non_json_content_still_valid():
    """⑤ 不强制 JSON 时，回答仍是合格字符串（不做过度断言）。"""
    resp = chat("随便说一句")
    assert_valid_response(resp)
```

## 五、异常 payload 校验（1.5h）

> 接口测试要测"该报错的场景"。本机实测 3 类：

```python
def test_empty_messages_400():
    """⑥ 空消息列表 → 400（本机实测报错：empty conversation）"""
    r = requests.post(f"{BASE_URL}/v1/chat/completions",
                      json={"model": "ornith1.5-35b", "messages": []},
                      timeout=10)
    assert r.status_code == 400

def test_bad_temperature_400():
    """⑦ 非法 temperature 值 → 400（本机实测超限报 400）。"""
    r = requests.post(f"{BASE_URL}/v1/chat/completions",
                      json={"model": "ornith1.5-35b",
                            "messages": [{"role": "user", "content": "hi"}],
                            "temperature": 100},
                      timeout=10)
    assert r.status_code == 400

def test_missing_model_404():
    """⑧ 不存在的模型 → 404（本机实测）。"""
    r = requests.post(f"{BASE_URL}/v1/chat/completions",
                      json={"model": "不存在的模型",
                            "messages": [{"role": "user", "content": "hi"}]},
                      timeout=10)
    assert r.status_code == 404

def test_error_body_has_message():
    """⑨ 4xx 响应 body 里有 error.message（本机结构）。"""
    r = requests.post(f"{BASE_URL}/v1/chat/completions",
                      json={"model": "不存在的模型",
                            "messages": [{"role": "user", "content": "hi"}]},
                      timeout=10)
    assert r.status_code == 404
    assert "error" in r.json()
```

> 异常态测试的价值：**锁定服务错误行为不被篡改**。比如某天 404 变成 500，这些用例会立刻红。
