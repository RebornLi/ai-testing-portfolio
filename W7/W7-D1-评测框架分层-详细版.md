## 一、为什么要分层（1.5h）★ 今日重点

> 一句话：**零散脚本只能"用"，封装成框架才能"测、复用、进流水线"。**

### 对比

| 形态 | 结构 | 缺点 |
|---|---|---|
| 单脚本 | 一个 200 行的 `eval.py` 啥都写 | 改一处动全身，不能单独测 |
| **框架** | `system/`(被测) + `metrics/`(指标) + `evaluate.py`(引擎) + `tests/`(用例) | 改动隔离，可单独测每个模块 |

### 我们的四层

```
system/        被测系统（确定性 ReAct 骨架，复用 W4）
  ├── agent.py       ReActAgent / DeterministicPlanner / Memory
  └── tools.py       工具集 add/multiply/lookup
metrics/       四维度指标封装（统一 score() 接口）
  └── __init__.py    Tool / Memory / Cost / DeepEval 四类
evaluate.py    评测引擎：被测 agent + 场景 → 四维度打分
run_evaluation.py  CLI 一键入口：打印报告 + 写 reports/
tests/         pytest 全量用例（覆盖四维度）
```

## 二、统一 score() 接口（1.5h）★ 核心

> 关键设计：**所有指标都返回 `(score, passed, errors)` 三元组**。
> 这样引擎不用关心具体维度，直接 `sum(score) / n` 算总分。

```python
"""metrics/__init__.py — 四维度指标封装（离线确定性）"""


class ToolCallingMetric:
    """维度1：工具调用 —— name/args/参数名/顺序/次数 全对。"""

    def __init__(self, expected, threshold=1.0):
        self.expected = expected
        self.threshold = threshold
        self.errors = []

    def score(self, trajectory):
        """trajectory: list[ToolCall]，返回 (score, passed, errors)。"""
        actual = [{"name": c.name, "args": c.args, "result": c.result}
                  for c in trajectory]
        if len(actual) != len(self.expected):
            self.errors.append(f"次数 {len(actual)} != 期望 {len(self.expected)}")
        for i, (a, e) in enumerate(zip(actual, self.expected)):
            if a["name"] != e["name"]:
                self.errors.append(f"步骤{i} 工具名不符")
            if a["args"] != e["args"]:
                self.errors.append(f"步骤{i} 参数不符")
        passed = len(self.errors) == 0
        score = 1.0 if passed else 0.0
        return score, passed, self.errors
```

## 三、被测系统：确定性 ReAct（2h）★ 产出①

> 复用 W4 骨架。`DeterministicPlanner` 是**有状态**的（`index` 累加），一次 run 即耗尽。

```python
"""system/agent.py — ReAct Agent 核心（确定性，可测试）"""
from tools import invoke_tool


class ReActAgent:
    """按规划器动作序列执行，记录轨迹，强制终止。"""

    def __init__(self, planner, max_iterations=10):
        self.planner = planner
        self.max_iterations = max_iterations

    def run(self, initial_prompt):
        """返回 {"answer", "trajectory", "reason"}。
        reason: stopped / sequence_end / max_iterations"""
        trajectory, state = [], ""
        for _ in range(self.max_iterations):
            try:
                decision = self.planner(trajectory, state)
            except StopIteration:
                return {"answer": None, "trajectory": trajectory,
                        "reason": "sequence_end"}
            if "answer" in decision:
                return {"answer": decision["answer"],
                        "trajectory": trajectory, "reason": "stopped"}
            name, args = decision["tool"]
            result = invoke_tool(name, args)
            trajectory.append((name, args, result))
            state += f"\n[{name} {args} -> {result}]"
        return {"answer": None, "trajectory": trajectory,
                "reason": "max_iterations"}


class DeterministicPlanner:
    """确定性规划器：按固定动作序列执行（有状态，run 一次耗尽）。"""
    def __init__(self, steps):
        self.steps, self.index = list(steps), 0

    def __call__(self, history, state):
        if self.index >= len(self.steps):
            raise StopIteration
        kind, *rest = self.steps[self.index]
        self.index += 1
        if kind == "tool":
            return {"tool": (rest[0], rest[1])}
        return {"answer": rest[0]}
```

## 四、踩坑：answer=None 的真 bug（1.5h）★ 今日踩坑★

> 第一次跑 `evaluate.py`，四维度总分就是 1.000，但我**心里犯嘀咕**——
> 工具调用那维度的 `answer` 字段居然是 `None`（应该是"结果是14"）！

### 复现

```python
tc = run_tool_calling_case(
    [("tool", "add", {"a": 3, "b": 4}),
     ("tool", "multiply", {"a": 7, "b": 2}),
     ("answer", "结果是14")],
    tool_expected=[
        {"name": "add", "args": {"a": 3, "b": 4}, "result": 7},
        {"name": "multiply", "args": {"a": 7, "b": 2}, "result": 14},
    ],
)
print("answer =", repr(tc.get("answer")))   # 实际: None  期望: '结果是14'
```

### 根因（先形成假设再验证）

```python
def run_tool_calling_case(steps, tool_expected):
    agent = ReActAgent(DeterministicPlanner(list(steps)))
    traj = agent.run("算")["trajectory"]          # ← 第 1 次 run
    score, passed, errors = ToolCallingMetric(tool_expected).score(traj)
    answer = agent.run("算")["answer"]            # ← 第 2 次 run（BUG！）
    # DeterministicPlanner 有状态，index 已到头 → 第 2 次 run 直接 sequence_end → answer=None
```

> 这跟 W6 反复踩过的坑是同一个：**有状态规划器复用会耗尽**。得分掩盖了 answer 丢失。

### 修复（新实例，不复用）

```python
def run_tool_calling_case(steps, tool_expected, max_iter=10):
    agent = ReActAgent(DeterministicPlanner(list(steps)), max_iterations=max_iter)
    traj = agent.run("算")["trajectory"]
    score, passed, errors = ToolCallingMetric(tool_expected).score(traj)
    # ★ 取 answer 必须另建一个 agent，否则确定性序列耗尽拿空答案
    answer = ReActAgent(DeterministicPlanner(list(steps))).run("算")["answer"]
    return {"name": "工具调用", "score": score, "passed": passed,
            "errors": errors, "answer": answer, "replay": agent.replay(traj)}
```

## 五、evaluate.py 跑通一键评测（2h）★ 产出②

```python
"""evaluate.py — 四维度打分引擎"""
from reports.report import EvaluationReport
from metrics import (ToolCallingMetric, MemoryMetric,
                     CostLatencyMetric, DeepEvalMetric)


def run_full_evaluation():
    # 维度1：工具调用
    tc = run_tool_calling_case(
        [("tool", "add", {"a": 3, "b": 4}),
         ("tool", "multiply", {"a": 7, "b": 2}),
         ("answer", "结果是14")],
        tool_expected=[{"name": "add", "args": {"a": 3, "b": 4}, "result": 7},
                        {"name": "multiply", "args": {"a": 7, "b": 2}, "result": 14}],
    )
    # 维度2：记忆
    mem = Memory()
    class RememberingPlanner:
        turn = 1
        def __call__(self, prompt, memory, maxit):
            if self.turn == 1:
                memory.write("name", "小明"); memory.write("city", "北京")
                self.turn += 1; return {"answer": "记下"}
            city = memory.read("city"); self.turn += 1
            return {"answer": f"你喜欢{city}" if city else "忘了"}
    planner = RememberingPlanner()
    MemoryAgent(mem, planner).run("第1轮")
    MemoryAgent(mem, planner).run("第2轮")
    mem_answer = MemoryAgent(mem, planner).run("第3轮")["answer"]
    mem = run_memory_case(mem, {"name": "小明", "city": "北京"}, mem_answer)

    # 维度3：成本/延迟（都在预算内）
    cost = run_cost_case(cost=0.5, latency=1.0)

    # 维度4：DeepEval 离线兜底
    ee = run_deepeval_case(actual="我喜欢北京", expected="北京", keyword="北京")

    tests = [tc, mem, cost, ee]
    total = sum(t["score"] for t in tests) / len(tests)
    passed = sum(1 for t in tests if t["passed"]) == len(tests)
    return EvaluationReport(tests, total, passed)
```
