## 一、项目结构规范（1h）★ 今日重点

> 一个专业的 pytest 项目长什么样？记住这个骨架，后面所有项目都能套。

### 1.1 标准结构
```
jd-validator/
├── src/                    # 工具/库代码（被测的"产品"）
│   ├── __init__.py         # 让 src 成为包
│   ├── salary_parser.py    # D4 的薪资解析
│   ├── jd_stats.py         # D3 的统计分析
│   └── report.py           # D5 的报告生成
├── tests/                  # 测试代码
│   ├── __init__.py
│   ├── conftest.py         # 共享 fixture
│   ├── test_salary_parser.py
│   ├── test_jd_stats.py
│   └── test_report.py
├── data/                   # 测试数据
│   └── jd_data.json
├── reports/                # 生成的报告输出
├── requirements.txt        # 依赖清单
├── pytest.ini              # pytest 配置
├── .gitignore              # 忽略规则
└── README.md
```

### 1.2 为什么要分层（src/ vs tests/）
- `src/` = **产品代码**（工具、库），是"被测对象"
- `tests/` = **测试代码**，是"裁判"
- 两者分离：测试可以反复测同一个工具，工具也不会"污染"测试

### 1.3 命名铁律
- 测试文件：`test_*.py` 或 `*_test.py`
- 测试函数：`test_...()`
- fixture：`conftest.py` 里定义，跨测试共享
- `__init__.py`：空文件即可，让目录变成 Python 包

### 3.1 `src/salary_parser.py`（D4 落地）
```python
"""薪资区间解析工具"""
import re


def parse_salary(salary):
    """把薪资字符串解析成 (最低, 最高) 元组；无法解析返回 None。"""
    if salary is None:
        return None
    s = str(salary).strip()
    if not s or s in ("面议", "不详", "待定", "--"):
        return None
    if "/天" in s or "元/天" in s:
        return None
    s = s.split("·")[0]
    m = re.match(r"^([\d.]+)\s*[/-]\s*([\d.]+)", s)
    if not m:
        return None
    lo_s, hi_s = m.group(1), m.group(2)
    mult = 10000 if "万" in s else (1000 if "k" in s.lower() else 1)
    return (int(round(float(lo_s) * mult)), int(round(float(hi_s) * mult)))
```

### 3.2 `src/jd_stats.py`（D3 落地）
```python
"""JD 统计分析工具"""
import json
from collections import Counter


def load_data(path="data/jd_data.json"):
    with open(path, encoding="utf-8") as f:
        return json.load(f)


def ai_ratio(jobs):
    ai = sum(1 for j in jobs if j.get("相关度") == "AI相关")
    return round(ai / len(jobs), 4) if jobs else 0.0


def city_distribution(jobs):
    return Counter(j.get("城市", "未知") for j in jobs)


def top_cities(jobs, n=5):
    return city_distribution(jobs).most_common(n)
```

### 3.3 `src/report.py`（D5 新做，统计报告）
```python
"""生成 JD 统计报告（Markdown 格式）"""
import json
from collections import Counter
from collections import defaultdict
from .salary_parser import parse_salary


def load_data(path="data/jd_data.json"):
    with open(path, encoding="utf-8") as f:
        return json.load(f)


def grade_salary(salary):
    r = parse_salary(salary)
    if r is None:
        return "面议/无"
    mid = (r[0] + r[1]) // 2
    if mid < 10000:   return "1万以下"
    if mid < 15000:   return "1-1.5万"
    if mid < 20000:   return "1.5-2万"
    if mid < 30000:   return "2-3万"
    return "3万以上"


def build_report(path="data/jd_data.json"):
    """生成报告文本（供测试断言 + 命令行输出）。"""
    jobs = load_data(path)
    cities = Counter(j.get("城市", "未知") for j in jobs)
    grades = Counter(grade_salary(j.get("薪资")) for j in jobs)
    edu = Counter(j.get("学历", "未知") for j in jobs)
    ai = sum(1 for j in jobs if j.get("相关度") == "AI相关")
    parsed = sum(1 for j in jobs if parse_salary(j.get("薪资")) is not None)

    lines = [
        f"# JD 统计报告",
        f"- 总岗位数：{len(jobs)}",
        f"- AI 相关占比：{round(ai/len(jobs), 4)}",
        f"- 薪资可解析率：{round(parsed/len(jobs), 4)}",
        f"- 城市 TOP5：{cities.most_common(5)}",
        f"- 薪资档位：{dict(grades.most_common())}",
        f"- 学历分布：{dict(edu.most_common())}",
    ]
    return "\n".join(lines)


if __name__ == "__main__":
    print(build_report())
```

## 四、pytest.ini 配置（1h）

> 配置好后，`pytest` 一行就跑全部，不用记一堆参数。

`pytest.ini`：
```ini
[pytest]
testpaths = tests
addopts = -v
pythonpath = src
markers =
    api: 接口测试
    slow: 慢速测试
```

> 关键项：
> - `testpaths`：默认测哪个目录
> - `pythonpath`：让 `from salary_parser import ...` 不用写 `sys.path`（但 D5 我们仍保留手动 `sys.path` 以演示原理）
> - `markers`：注册标记，避免"未注册标记"警告

### 4.1 运行
```bash
cd ~/ai-testing-portfolio/jd-validator
pytest                 # 自动跑 tests/ 全部
pytest --cov=.         # 加覆盖率（需 pip install pytest-cov）
```
