> 目标：自建 RAG 系统 + 全链路质量保障——检索可量化、幻觉可检测、答案可打分、报告可复现
> 验收：`rag-demo/` 独立工程 + pytest 53 用例全绿 + 里程碑 README + commit

---

## 🎯 本周总目标

阶段「AI 应用评测」的 **RAG 层**。RAG = 检索增强生成（给模型一本「参考书」，查了再答）。本周要**从「造 RAG」到「评 RAG」**：把「分块 → 嵌入 → 向量库 → 检索 → 答案 → 报告」整条链路拆开，每个环节都设计确定性 pytest 去抓质量。

四个关键问题（对应四天）：
1. **检索找得准不准？**（D3）→ Recall@K / Precision@K / MRR / HitRate
2. **答案有没有编造？**（D4）→ 确定性接地检测（幻觉）
3. **答案答没答到点？**（D5）→ 答案相关性 + 综合质量门
4. **整条流水线综合质量？**（D6）→ 端到端评估报告

> ⚠️ 本周核心方法论：**重量级东西（真实模型 / FAISS）进测试就 mock**，只测「集成层逻辑」，保证 CI 离线、确定、可复现。

## 📅 每日任务

### D1（09-04）RAG 入门与向量检索 ★
- 学习：RAG 是什么（闭卷 vs 开卷）；全流程 4 环节；为什么需要它（知识滞后 + 幻觉）
- 实战：确定性嵌入（numpy 词袋哈希）+ 余弦相似度检索 + Top-K
- 产出：`rag/rag_utils.py`（分块 + 确定性嵌入 + 检索）
- 验收：画出 RAG 流程图 + 确定性检索原型 + commit

### D2（09-05）接入真实 Embedder 与向量库 ★
- 学习：真实 Embedder vs 教学嵌入的设计取舍；工厂模式 mock/real 可切换
- 实战：embedder 工厂（MockEmbedder 默认）+ store（Mock / FAISS）+ pipeline 集成层
- 产出：`rag/embedders.py` / `store.py` / `pipeline.py`
- 验收：`test_rag_integration.py` 9 用例全绿（纯 mock 集成层，不依赖模型）

> 本机实测发现：Qwen3-Embedding-8B 在 GB10 上 bf16 会 OOM，所以默认走 mock，需要真实向量时手动切 `mode="real"`。

### D3（09-06）检索质量评估 ★ 今日重点
- 学习：「检索质量」和「回答质量」是两件事；四个检索指标
- 实战：`eval_metrics.py`（Recall@K / Precision@K / MRR / HitRate）+ golden 集 + 质量门
- 产出：`rag/eval_metrics.py` / `eval_engine.py`
- 验收：`test_rag_eval.py` 9 用例全绿

### D4（09-07）端到端 RAG 问答 + 幻觉检测 ★
- 学习：幻觉两源（检索错误 vs 生成编造）；接地（grounding）概念
- 实战：确定性接地检测（句子级关键词重叠打分，阈值 0.5）
- 产出：`rag/grounding.py`
- 验收：`test_rag_d4.py` 9 用例全绿（含「无上下文全部判幻觉」的安全失败）

> 认知边界：关键词重叠认不出同义改写（「哈希表」↔「键值对」）；真实系统用 LLM-as-Judge / embedding 相似度。

### D5（09-09）答案质量打分 + 质量门 ★
- 学习：答案相关性（覆盖问题多少关键词）；「相关」和「忠实」是两件事
- 实战：`quality.py`（相关性 + 完整性 + 综合分 + 质量门 0.6）；StaticAnswerer 解耦真实模型
- 产出：`rag/quality.py`
- 验收：`test_rag_quality.py` 11 用例全绿

### D6（09-10）端到端评估报告
- 学习：把检索 / 幻觉 / 答案三条线整合成一份端到端报告
- 实战：`RagEvaluator` 评估引擎 + 报告格式化（`✅` / `❌` + 综合分，阈值 0.6）
- 产出：`rag/report.py`
- 验收：`test_rag_report.py` 9 用例全绿

### D7（09-11）里程碑 + 复盘
- 任务：写 `rag-demo/README.md`（里程碑版）；全量 53 用例验证；复盘
- 产出：里程碑 README + 53 用例验证 + 复盘记录
- 验收：全部 push + 复盘（完成度 / 卡点 / 下周预习）
