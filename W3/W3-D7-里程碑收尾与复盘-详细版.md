### 2. 关键技术沉淀

- **工厂模式解耦**：`get_embedder(mode="mock"/"real")`、`get_store(mode="mock"/"faiss")`、`get_store`，测试永远走 mock，真实模型手动切 `mode="real"`
- **确定性替代**：没有真实 embedding 服务时，用确定性词袋嵌入 + numpy 余弦相似度做原型，保证笔记+代码可跑可验证
- **质量门模式**：`composite_score = 相关×0.5 + 忠实×0.5`，阈值 0.6 卡质量，`QualityGate` 封装 `score()` 和 `is_pass()`
- **TDD 实测**：每个模块先写测试、跑通再 commit，不靠"应该没问题"

### 3. 卡点与解决

| 卡点 | 解决 |
|---|---|
| `:8081` embedding 服务未启动 | 用确定性词袋嵌入兜底，笔记诚实标注留待后续接入 |
| faiss/chromadb 未安装 | 用 `MockVectorStore` 离线兜底，`FAISSVectorStore` 留真接口 |
| faiss 旧 API `IndexFlatCosine` 在新版（1.15）已移除 | 2026-08-28 装 faiss-cpu 1.15 + 实测：改用 `normalize_L2` + `IndexFlatIP`（归一化后内积=余弦）；已修正 W3-D2 store.py |
| 空 golden 集 NaN | `np.mean([])` 返回 NaN → 空行兜底 0.0 |
| 答案器导入名错误 | 发现实际是 `StaticAnswerer`，改 import |

### 4. 经验沉淀（可复用到下周）

1. **先探测环境再写代码**：装库前 `ls` 确认是否已装，避免重复劳动
2. **TDD + 跑通验证**：笔记里写"期望全绿"，实际必须真的跑绿才交付
3. **笔记与代码同步**：每份笔记对应真实可运行代码，不是纸上谈兵
4. **空集边界处理**：空 golden、空 query 都要有兜底，避免除零/NaN
