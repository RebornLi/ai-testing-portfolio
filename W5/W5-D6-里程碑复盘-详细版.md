## 一、本周 5 个概念汇总（1.5h）★ 产出①

> 一张表，把本周学的 ML/DL 扫盲串成一条线。

| 天 | 概念 | 一句话 | 关键公式/思想 |
|---|---|---|---|
| D1 | 神经网络直觉 | 一个神经元 = 加权求和 + 激活，学习就是调权重 | `z = Σx·w + b`，`a = ReLU(z)` |
| D2 | embedding | 含义编码成向量，能算"国王-男+女≈女王" | `cosine(a,b) = a·b / (‖a‖‖b‖)` |

| D4 | 训练 vs 推理 | 训练学规律（动权重）、推理应用规律（不动权重） | 训练：前向→Loss→反向→调参 |
| D5 | Transformer/Attention | 每个位置看全部位置，Q·K→scale→softmax→×V | attention = softmax(QKᵀ/√d)V |

## 二、核心公式速查（★ 产出）

```
① 神经元：  a = ReLU(Σ xᵢ·wᵢ + b)
② 相似度：  cosine = dot(a,b) / (||a|| · ||b||)
③ 过拟合：  train_loss ↓  ·  val_loss ↑  → 该停了
④ 训练循环：pred→Loss=mse(pred,y)→grad→w = w - lr·grad
⑤ attention：scores = Q·Kᵀ / √d  →  softmax  →  out = attn·V
```

> 记忆主线：**神经元学东西（D1）→ 把意义变成向量（D2）→ 学得不好会过拟合（D3）→ 训练学规律、推理用规律（D4）→ 用 Attention 看全局（D5）。**

## 五、本周卡点回顾（1.5h）★ 产出

| 卡点 | 解决 |
|---|---|
| 反向传播到底在调什么 | 明白是"梯度下降调权重"，梯度指向让 loss 增大的方向，要往反方向挪 |
| 过拟合时 train loss 也在降 | 关键看**验证 loss 反弹**，不是只看训练 loss |
| attention 为什么要 scale ÷√d | 点积随维度增大→softmax 饱和→梯度趋 0→学不动 |
| 训练和推理别混 | 训练算 Loss+反向；推理只前向、不动权重 |

## ⏰ 复盘：这周给我最大的三个认知

1. **训练 = 动权重学规律，推理 = 不动权重用规律**——这条贯穿整个模型周期。
2. **过拟合看验证 loss 反弹**，不是看训练 loss。
3. **Attention 让每个位置看到全局**，这是 Transformer 碾压 RNN 的核心。
