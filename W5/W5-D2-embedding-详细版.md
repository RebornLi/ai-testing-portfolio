## 一、embedding 是什么（1.5h）★ 今日重点

> 一句话：**embedding = 给每个东西一个"多维向量"，让含义相近的，向量在空间里也相近。**

### 1.1 为什么需要 embedding
- 模型只能吃**数字**，不能直接吃"词"。
- token 是离散的整数（如 "猫"=103，"狗"=457），103 和 457 之间没有"相似"关系 → 纯靠数字毫无语义。
- 我们需要一种表示：**"猫"和"猫粮"应该比"猫"和"宇宙"更接近。**

### 1.2 embedding 的做法
- 给词表里每个词分配一个**稠密向量**（几十到几千维），每个维度代表一个"语义轴"。
- 训练后，语义相近的向量空间里也近。
- 直觉：
  - 维度1高 ≈ "是否指代人"
  - 维度2高 ≈ "是否具体可数"
  - 维度3高 ≈ "是否抽象/带情感"
  - （维轴含义是"涌现"出来的，模型自己学的，人类事后解释）

### 1.3 训练时怎么变
- 初始随机向量（乱填）。
- 训练时靠"相邻出现的词，向量趋同"（分布假设：上下文相似 → 含义相近）。
- 越训越准 → 上线还能继续微调。

## 二、余弦相似度：怎么衡量"两个向量多接近"（1.5h）★ 核心

> 关键指标：**余弦相似度（cosine similarity）**，取值 [-1, 1]，越接近 1 越相似。

### 2.1 公式
```
cos(A,B) = (A·B) / (|A| × |B|)
```
- 分子点积，分母各自模长归一化 → 只看方向。
- 结果：`1.0` 同向（同义）／`0` 正交（无关）／`-1.0` 反向（反义）。

> 为什么看方向不看长度？词义相似看方向，长度受使用频率等干扰，归一化吃掉。

## 三、实战：numpy 手算迷你词表（2h）★ 产出①

```python
"""D2-embedding 手算：cosine 相似度 · ML/DL 扫盲"""
import numpy as np

def cosine(a, b):
    """两个向量余弦相似度 [-1, 1]。"""
    a, b = np.array(a), np.array(b)
    num = np.dot(a, b)
    den = np.linalg.norm(a) * np.linalg.norm(b)
    return num / den if den else 0.0

# 迷你词表（示意向量，非真实训练值）
words = {
    "猫":  [0.9, 0.8, 0.1],
    "狗":  [0.85, 0.75, 0.15],  # 与"猫"很接近
    "猫粮":[0.8, 0.6, 0.3],    # 与"猫"较近
    "量子":[0.05, 0.1, 0.9],   # 抽象科学，与动物远
    "国王":[0.9, 0.0, 0.7],    # 指代人物
}
print(f"猫 vs 狗   : {cosine(words['猫'], words['狗']):.3f}")     # 最高
print(f"猫 vs 猫粮: {cosine(words['猫'], words['猫粮']):.3f}")   # 中高
print(f"猫 vs 量子: {cosine(words['猫'], words['量子']):.3f}")   # 低
print(f"猫 vs 国王: {cosine(words['猫'], words['国王']):.3f}")   # 低
```

**期望**："猫-狗" 最高，"猫-量子/国王" 较低。

## 四、魔法例子：国王-男+女≈女王（1.5h）★ 重点

```python
"""D2-向量关系：国王 - 男 + 女 ≈ 女王"""
import numpy as np

def cosine(a, b):
    a, b = np.array(a), np.array(b)
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)) if np.linalg.norm(a) and np.linalg.norm(b) else 0.0

words = {
    "国王": [0.80, 0.10, 0.70],
    "女王": [0.78, 0.10, 0.72],  # 同国王，性别女
    "男":   [0.70, 0.05, 0.20],
    "女":   [0.68, 0.05, 0.25],
    "王子": [0.75, 0.05, 0.55],
    "平民": [0.30, 0.40, 0.10],
}
# 关键：转成 np.array 才能做向量加减（list 不能相减！）
result = np.array(words["国王"]) - np.array(words["男"]) + np.array(words["女"])
nearest = max(words, key=lambda k: cosine(result, words[k]))
print(f"国王 - 男 + 女 最近的是: {nearest}")   # 期望：女王
```

**期望**：结果向量与词表各词算相似度，最近的是"女王"。"性别"这个关系被减法剥离成可迁移的方向。

"""D2-连本地 :8081 取真实向量（服务可用时）"""
import urllib.request, json
def embed(text):
    req = urllib.request.Request(
        "http://127.0.0.1:8081/embed",
        data=json.dumps({"text": text}).encode(),
        headers={"Content-Type": "application/json"})
    with urllib.request.urlopen(req, timeout=5) as r:

## 六、概念笔记② 落盘（1.5h）★ 产出

> 一句话记忆点：

1. **embedding** = 把离散对象变成稠密向量，含义相近 → 向量相近。
2. **为什么需要**：token 是稀疏整数，无相似关系；embedding 补上"语义距离"。
3. **训练时变**：靠"相邻出现的词语义相近"（分布假设），越训越准。
4. **余弦相似度**：`cos(A,B)=A·B/(|A||B|)`，范围[-1,1]，只看方向，越接近1越相似。
5. **魔法例子**：`国王-男+女≈女王` —— 向量减法把"关系"剥离成可迁移方向。
6. **应用**：RAG 检索、文本聚类、推荐、语义搜索全靠 embedding。
