## 一、一页纸面试速记 · ML/DL 扫盲（★ 产出①）

> 面试官问"这周你学什么了"，照着这条线讲：

### 1. 神经网络直觉
> **一句话**：神经网络 = 一堆旋钮（权重），学习就是把旋钮调到让预测接近答案。
- 神经元：`z = Σx·w + b`，弯折激活 `a = ReLU(z)`。
- 学习三件套：损失（答错罚多少）→ 梯度下降（蒙山下山）→ 反向传播（谁负责谁调）。
- 学习率太大会爆炸（发散了），太小又慢。

### 2. embedding
> **一句话**：把含义编码成向量，相似的词向量就近。
- `cosine = 点积 / (模长乘积)`，值越接近 1 越相似。
- 魔法：`国王 - 男 + 女 ≈ 女王`——关系被编码成向量方向。

### 3. 过拟合 / 欠拟合
> **一句话**：过拟合=对训练对测试错（死记）；欠拟合=都对不上（学不会）。
- 信号：训练 loss 降、验证 loss 反弹 = 过拟合，该停了。
- 治法：早停 / Dropout / 正则 / 更多数据。

### 4. 训练 vs 推理
> **一句话**：训练=学规律（动权重）；推理=应用规律（不动权重）。
- 训练：喂带标签数据 → 算 Loss → 反向传播 → 调权重。
- 推理：新数据直接前向 → 出结果，不动权重。
- 上线只做推理（慢卡 vs 快省）。

### 5. Transformer / Attention
> **一句话**：每个 token 同时看全部 token，注意力决定关心谁。
- Q 查、K 标、V 内容。`scores = Q·Kᵀ / √d` → softmax → `×V` 加权平均。
- 比 RNN 强：可并行、不丢远距离信息、重点不被稀释。
- 多头注意力：并行多组 Q/K/V，各看不同角度。

## 二、模拟面试：5 概念各 3 问（★ 产出②）

> 自己出题自己答，答不上来 = 还没掌握。

**神经元**
- Q：没有激活函数会怎样？→ A：叠多少层还是直线，学不了非线性。
- Q：学习率为什么不能太大？→ A：会梯度爆炸，权重发散。
- Q：反向传播在算什么？→ A：算每个权重对 loss 的梯度，往反方向挪。

**embedding**
- Q：cosine 为什么比欧氏距离好？→ A：归一化后只关心方向，不关心模长。
- Q：国王-女那个例子说明什么？→ A：词义关系=向量空间中的固定方向。

**过拟合**
- Q：怎么识别过拟合？→ A：验证 loss 反弹。
- Q：早停为什么有效？→ A：验证集提前预警模型开始背数据。
- Q：加数据为什么有用？→ A：模型没得背，只能学规律。

**训练/推理**
- Q：上线后为什么不能改模型？→ A：改了权重就变成训练了，推理只应用规律。
- Q：训练和推理唯一区别？→ A：训练调权重，推理不动。

**Transformer**
- Q：为什么 ÷√d？→ A：防点积太大、softmax 饱和、梯度趋 0。
- Q：attention 为什么比 RNN 强？→ A：一步看全局、并行、不丢信息。

## 三、最弱概念补强：Attention 公式再推导

> 这周最难的是一天 D5 的 attention。巩固它：

```python
"""attention 四步推导（巩固）"""
import numpy as np

# 3 个 token，每个一个 4 维向量；Q=K=V 只是演示，真实模型用不同矩阵投影
Q = np.array([[0.5, 0.1, 0.8, 0.2], [0.3, 0.9, 0.2, 0.6], [0.7, 0.2, 0.5, 0.4]], dtype=float)
K, V = Q, Q
d = Q.shape[1]                     # 维度 = 4

# 1. Q·K 点积：算每个词对当前的"匹配度"
scores = Q @ K.T                     # [seq, seq]
# 2. scale：防止分数太大
scores /= np.sqrt(d)
# 3. softmax：匹配度变概率分布（和=1）
# 注意：分母是 exp(scores) 的和，不是 scores 的和（新手常错）
weights = np.exp(scores) / np.exp(scores).sum(axis=1, keepdims=True)
scores = weights
# 4. 加权：用概率把 V 拼起来
out = scores @ V
```

> 关键认知：**softmax 把"分数"变成"关心多少"，关心多少决定这个词的 V 占多大比重。**
