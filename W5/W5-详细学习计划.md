## 🎯 本周总目标（对标计划 4.2 W5）

阶段二「AI 核心」第 5 周，补齐 AI 测试岗位最核心的底层直觉：

1. **神经网络直觉**：一个神经元怎么学东西，训练三件套（损失/梯度下降/反向传播）

## 📅 每日任务

### D1（08-28 周五）：神经网络直觉 — 神经元怎么学东西 ★
- 学习：一个神经元的数学直觉（权重/偏置/激活）+ 损失/梯度下降/反向传播
- 实战：手算一个小神经元的前向传播（给输入、权重，算输出）
- 产出：概念笔记① 神经单元数学直觉 + 一句话笔记
- 验收：能口述"一个神经元怎么学东西"

### D2（08-29 周六）：embedding — 把含义变成坐标 ★
- 学习：embedding 是什么、为什么需要、训练时怎么变
- 实战：用 numpy 造一个迷你词表，手算几个词的向量相似度（cosine）
- 产出：概念笔记② embedding + 魔法例子（国王女王）
- 验收：能解释 embedding + 能算两个向量的相似度

### D3（08-30 周日）：过拟合 / 欠拟合 / 偏差-方差 ★
- 学习：训练 loss vs 验证 loss 的关系、过拟合症状、治法（Dropout/正则/数据增强/早停）
- 实战：观察过拟合曲线（画训练/验证 loss 对比图）
- 产出：概念笔记③ 偏差方差表 + 一句话记忆
- 验收：给一条损失曲线能判断欠拟合/过拟合/正好

### D4（08-31 周一）：训练 vs 推理 全流程实战
- 学习：训练循环（喂数据→出结果→算Loss→反向传播→调权重）vs 推理（不动权重）
- 实战：用一个固定小模型跑 5 次前向，模拟"推理不动权重"
- 产出：训练流水线图 + 训练/推理对比表
- 验收：能用大白话给面试官讲清"训练=学规律，推理=应用规律"

### D5（09-01 周二）：Transformer 结构深度 ★
- 学习：Self-Attention 原理（Q/K/V、注意力权重）、为什么比 RNN 强
- 实战：手算一个小 attention 权重（3 个 token 的 Q·K 点积）
- 产出：Transformer 流程图 + Attention 原理图
- 验收：能画出 Transformer 主链路，能讲清 attention 在干嘛

### D6（09-02 周三）：本周里程碑收尾 + 复盘
