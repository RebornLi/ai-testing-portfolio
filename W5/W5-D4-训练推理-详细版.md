## 一、训练循环：一个模型怎么炼成（1.5h）★ 今日重点

> 一句话：**训练 = 反复试错，直到模型自己"悟"出规律。**

训练是一条转个不停的流水线：

```
喂数据 → 模型出预测 → 和真值比 → 算 Loss → 反向传播算梯度 → 优化器调权重 → 重来
```

### 四个环节逐个拆解

**① 喂数据**
- 一次喂一批（batch）：输入 x，期望输出 y。

**② 模型出预测**
- 数据穿过神经元 → 模型给出当前预测 `pred`。

**③ 算 Loss**
- `loss = (pred - y)²` 的均值。pred 和真值差多少 = 现在有多"瞎"。

**④ 反向传播 + 调权重**
- 从 Loss 往后推：谁该负责？每个权重按梯度挪一步：
  `w = w - 学习率 × 梯度`
- 这一轮下来，模型比上一轮"更懂"这条数据。

### 训练循环（完整版）

```python
"""训练循环：不断试错，直到 loss 足够小"""
import numpy as np

def train(model, X, y, epochs=100, lr=0.1):
    losses = []
    for epoch in range(epochs):
        # 1. 前向：模型出预测
        pred = model.forward(X)
        # 2. 算 Loss
        loss = np.mean((pred - y) ** 2)
        losses.append(loss)
        # 3. 反向传播 + 4. 调权重（这里用解析梯度简化）
        grad = 2 * (pred - y) / len(y)
        model.weights -= lr * grad
        if epoch % 20 == 0 or epoch == epochs - 1:
            print(f"epoch {epoch:3d} | loss = {loss:.4f}")
    return losses
```

> 训练的本质：**不是把答案背下来，而是不断调权重，让预测逼近真实。** 训练完 = 权重定型 = 模型"学会"了。

## 二、推理：用训练好的模型干活（1.5h）★ 核心区分

> 一句话：**推理 = 模型上线干活，把学到的规律用出去。**

### 推理 vs 训练，本质区别

| | 训练（Train） | 推理（Inference） |
|---|---|---|
| 目的 | **学会**规律 | **应用**规律 |
| 动权重吗 | ✅ 动（每轮调 w） | ❌ 不动（固定死） |
| 输入 | 带标签的数据（有答案） | 任意新数据（没答案） |
| 要不要算 Loss | ✅ 要（对比真值） | ❌ 不要 |
| 反向传播 | ✅ 要（算梯度调参） | ❌ 不要（直接前向） |
| 速度 | 慢、烧卡 | 快、省钱 |
| 阶段 | 离线开发 | 上线服务 |

> 记住一句话：**训练 = 学习（动权重）；推理 = 应用（不动权重）。**
> 训练好的模型存成文件，上线后只用推理——这就是为什么部署后模型权重"纹丝不动"。

## 三、实战：numpy 手写一个会训练的小模型（2h）★ 产出①

> 让模型"学会" y = 2x 这条直线。先训练，再固定权重推理。

```python
"""D4-训练 + 推理全流程 · ML/DL 扫盲"""
import numpy as np

class SimpleLinearModel:
    """最简单的模型：y = w·x，只有一个权重 w。"""
    def __init__(self):
        self.weights = np.array([0.0])   # 初始瞎猜

    def forward(self, X):
        """前向传播 = 推理：输入 x，输出 w·x（不动权重）。"""
        return self.weights * X

# 训练数据：一条有噪声的直线 y ≈ 2x
np.random.seed(42)
X = np.linspace(1, 10, 20)
y = 2 * X + np.random.normal(0, 1, 20)

model = SimpleLinearModel()

# 训练：不断调权重，直到会 y=2x
def train(model, X, y, epochs=500, lr=0.01):
    for epoch in range(epochs):
        pred = model.forward(X)                 # ① 前向
        loss = np.mean((pred - y) ** 2)         # ② 算 Loss
        grad = 2 * np.mean((pred - y) * X)      # ③ 梯度
        model.weights -= lr * grad              # ④ 调权重
    return model

trained = train(model, X, y)
print(f"训练完 w={trained.weights[0]:.3f}（理想 ≈ 2.0）")

# 现在模型"学好了"，固定权重，开始推理
print("\n=== 推理（不动权重）===")
for x in [5, 10, 15]:
    pred = trained.forward(np.array([x]))     # 直接前向，不调 w
    print(f"x={x:>2} → 模型推理输出 ≈ {pred[0]:.1f}")  # 越接近 2x 越准

# 对比：用"刚训练好的权重"推理新数据
print(f"\n推理示例：x=15 预测 ≈ {trained.forward(np.array([15]))[0]:.1f}（理想 30）")
```

**期望现象**：
- 训练完 w 逼近 2.0。
- 推理 x=15 → 约 30。新数据没被"背过"，模型靠学到的规律 y=2x 猜——这就是推理。

## 四、对比实验：训练好的 vs 没训练过的（1.5h）★ 产出

> 同一个新数据 x=15：
> - **没训练过**的模型 → 瞎猜。
> - **训练好**的模型 → 准确预测。
> 差异全在"权重对不对"——这就是训练的价值。

```python
"""D4-对比：训练过的模型推理更准"""
import numpy as np

def make_model(w):
    def forward(x):
        return w * x
    return forward

# 没训练过：权重瞎设成 0.3
random_forward = make_model(0.3)
# 训练好：权重已经是 2.0
trained_forward = make_model(2.0)

x_new = 15.0
print(f"新数据 x={x_new}，真实值 = 2*x = {2*x_new:.1f}")
print(f"未训练模型推理：{random_forward(x_new):.1f}  ← 瞎猜")
print(f"训练好的模型推理：{trained_forward(x_new):.1f}  ← 准！")
```

**期望**：未训练模型 4.5（错得离谱），训练好的 30（对）。

## 六、概念笔记④ 落盘（1.5h）★ 产出

> 一句话记忆点：

1. **训练循环** = 喂数据 → 出预测 → 算 Loss → 反向传播 → 调权重 → 重来。
2. **推理** = 固定权重，新数据直接前向出结果。
3. **核心区别**：训练动权重（学规律），推理不动权重（应用规律）。
4. **训练要算 Loss + 反向传播**；推理不要，直接前向。
5. **训练慢烧卡**；推理快省钱（上线只做推理）。
6. **价值**：训练过的模型权重对 → 新数据也准；没训练过 → 瞎猜。

## 七、面试口述版（大白话，别背术语）

> 训练就像学生刷题+对答案：做完一题，和标准答案比一比差多少（Loss），
> 发现自己哪里错了，回头调整思路（调权重），再多刷几遍，刷到"会了"为止。
> 推理就是考试答题：把学到的方法用出去，直接给出答案，这时候思路是定死的。
> 所以训练在离线阶段（烧 GPU），上线后只做推理（快、省钱）。

## ⏰ 卡点提示

- 训练时 loss 为什么不是一直降到 0？因为数据有噪声，且要防止过拟合。
- 为什么推理要"不动权重"？因为推理的目的是"应用学到的规律"，不是再学一遍——动了权重就变成训练了。
