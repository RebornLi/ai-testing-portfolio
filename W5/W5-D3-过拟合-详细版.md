## 一、过拟合 vs 欠拟合（1.5h）★ 今日重点

> 一句话：
> - **欠拟合** = 模型太笨，训练和测试都学不会。
> - **过拟合** = 模型太死，训练全对、测试全错 = 死记硬背。

### 1.1 两个症状对照表

| 状态 | 训练集 | 测试集 | 一句话 | 谁的问题 |
|---|---|---|---|---|
| **欠拟合** | 错 | 错 | 模型太简单，没学会 | 模型太笨 |
| **正好** | 对 | 对 | 学到了规律 | ✅ 理想 |
| **过拟合** | 对 | 错 | 死记答案，换个花样不会 | 模型太死 |

### 1.2 过拟合为什么危险
- 模型把训练集里的**噪声、偶发特征**也记住了（不是学规律，是背答案）。
- 换一组新数据就崩。
- ML 里最忌讳的就是过拟合——你以为学会了，其实只会背课表。

---

## 二、偏差-方差（1.5h）★ 核心概念

> 关键：**欠拟合 = 高偏差；过拟合 = 高方差。** 我们要在中间找平衡。

### 2.1 偏差（Bias）
- 模型"想得太简单"，没捕捉到真实规律。
- 表现：训练集也学不好 → **欠拟合**。
- 治法：更复杂模型 / 更多特征 / 训练更久。

### 2.2 方差（Variance）
- 模型"想得太死"，被训练集里的噪声带偏。
- 表现：训练集学得太好，换数据就崩 → **过拟合**。
- 治法：Dropout、正则、数据增强、早停、更多数据。

### 2.3 偏差-方差权衡
```
总误差 = 偏差² + 方差 + 不可约噪声
```
- 模型太简单 → 偏差主导（欠拟合）
- 模型太复杂 → 方差主导（过拟合）
- 目标：找一个"偏差和方差都不太大"的平衡点。

## 三、实战：画一条过拟合曲线（2h）★ 产出①

> 训练三个**多项式回归**（次数从低到高）。用高次多项式（模型太复杂）去拟合一条带噪声的直线 → 必然过拟合。
> 看训练集 loss 一路降，验证集 loss 先降后升（这就是过拟合的信号）。
> 用 ML 主流的 sklearn：`PolynomialFeatures` + `LinearRegression`。

```python
"""D3-过拟合 vs 欠拟合曲线 · ML/DL 扫盲（sklearn）"""
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import PolynomialFeatures

def mse(pred, target):
    """均方误差。"""
    return float(np.mean((pred - target) ** 2))

# 1. 造一条有噪声的真实规律 y = 2x
np.random.seed(42)
x_tr = np.linspace(-1, 1, 20).reshape(-1, 1)
y_tr = 2 * x_tr.ravel() + np.random.normal(0, 0.15, 20)   # 带噪声
x_val = np.linspace(-1, 1, 50).reshape(-1, 1)
y_val = 2 * x_val.ravel()         # 无噪声的真实曲线（验证用）

# 2. 训练三个不同"复杂度"的多项式
for degree in [1, 3, 15]:
    poly = PolynomialFeatures(degree).fit(x_tr)   # 多项式特征
    pred_tr = LinearRegression().fit(poly.transform(x_tr), y_tr).predict(poly.transform(x_tr))
    pred_val = LinearRegression().fit(poly.transform(x_tr), y_tr).predict(poly.transform(x_val))
    mt, mv = mse(pred_tr, y_tr), mse(pred_val, y_val)
    print(f"多项式次数={degree:2d} | 训练loss={mt:.3f} | 验证loss={mv:.3f}")
```

> 等价纯 numpy 写法：`np.polyfit(x_tr, y_tr, degree)` 得到系数 + `np.polyval(coeffs, x)` 预测，结果完全一致。

**期望现象（关键）**：

| 次数 | 训练loss | 验证loss | 判断 |
|---|---|---|---|
| 1（太简单） | 高 | 高 | 欠拟合（高偏差） |
| 3 | 中 | 中 | 正好 |
| 15（太复杂） | 极低 | 极高 | 过拟合（高方差） |

> **黄金信号**：训练 loss 一直在降，验证 loss 降到某点后**反弹上升** → 过拟合，该停了。

## 四、治法：怎么"救回"过拟合（1.5h）

> 四种常用手段，记住各自解决什么：

| 治法 | 原理 | 适用 |
|---|---|---|
| **早停（Early Stopping）** | 验证 loss 开始升就停 | 训练轮数过多时 |
| **Dropout** | 随机丢弃一部分神经元，逼模型不依赖单个特征 | 神经网络过拟合 |
| **正则化（L1/L2）** | 给权重加"惩罚项"，不让权重过大（模型别太极端） | 权重过分散时 |
| **数据增强 / 更多数据** | 喂更多样本，模型没得背，只能学规律 | 数据太少时 |

> 直觉：过拟合是因为"数据太少、模型太闲、有得背" → 要么给它更多数据，要么限制它的能力。

## 五、画图：训练 vs 验证 loss 对比（2h）★ 产出

> 用 matplotlib 把"过拟合"画出来，两条曲线一目了然。这就是面试时画的图。

```python
"""D3-画过拟合曲线 · matplotlib"""
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import PolynomialFeatures

np.random.seed(42)
x_tr = np.linspace(-1, 1, 20).reshape(-1, 1)
x_val = np.linspace(-1, 1, 50).reshape(-1, 1)
y_tr = (2 * x_tr.ravel() + np.random.normal(0, 0.15, 20))
y_val = 2 * x_val.ravel()

degrees = [1, 3, 15]
train_loss, val_loss = [], []
for d in degrees:
    poly = PolynomialFeatures(d).fit(x_tr)
    m = LinearRegression().fit(poly.transform(x_tr), y_tr)
    tr = np.mean((m.predict(poly.transform(x_tr)) - y_tr) ** 2)
    va = np.mean((m.predict(poly.transform(x_val)) - y_val) ** 2)
    train_loss.append(tr)
    val_loss.append(va)

plt.figure(figsize=(6, 4))
plt.plot(degrees, train_loss, 'o-', label="训练 loss")
plt.plot(degrees, val_loss, 's--', label="验证 loss")
plt.axvline(x=15, color="red", linestyle=":", alpha=0.6)
plt.annotate("过拟合起点", xy=(15, val_loss[-1]), xytext=(10, val_loss[-1] * 2),
             color="red")
plt.xlabel("多项式次数（模型复杂度）")
plt.ylabel("loss")
plt.legend()
plt.show()
```

**看什么**：训练 loss 一路往下，验证 loss 在 degree 15 反弹——那个"拐点"就是过拟合。

## 六、概念笔记③ 落盘（1.5h）★ 产出

> 一句话记忆点：

1. **欠拟合** = 训练测试都错，模型太笨。
2. **过拟合** = 训练对测试错，死记答案、换个花样不会。
3. **偏差-方差**：欠拟合=高偏差（学不够）；过拟合=高方差（学太死）。
4. **过拟合信号**：训练 loss 一直降，验证 loss 先降后升 → 早停。
5. **治法**：早停 / Dropout / 正则 / 更多数据（核心逻辑=别让模型有得背）。
6. **总误差** = 偏差² + 方差 + 不可约噪声 → 找一个平衡点。
