## 一、一个神经元到底在干嘛（1.5h）★ 今日重点

> 一句话：**神经网络 = 一堆"开关旋钮"叠起来。学习，就是把这些旋钮调到让预测接近真实答案。**

### 1.1 一个神经元的数学直觉
每个神经元干三件事，像一条流水线：

```
输入 x1,x2,...,xn
        ↓
加权求和：z = x1·w1 + x2·w2 + ... + xn·wn + b      ← 旋钮（权重 w + 偏置 b）
        ↓
弯折激活：a = σ(z)                                  ← 把直线弯成曲线
        ↓
输出 a
```

- **w（权重）= 旋钮**：每个输入对结果有多大发言权。w 越大，这个输入越"强势"。
- **b（偏置）= 起点**：就算没有输入，输出也有个基础值。
- **σ（激活函数）= 弯折**：把直直的量变弯，模型才认得"非线性"的东西。
  - 没有激活函数 → 叠 100 层还是等于一条直线 → 模型什么都学不会。

> 常用激活 ReLU：`σ(z) = max(0, z)`。负的压成 0，正的照旧。

### 1.2 多个神经元 → 一层 → 网络
- 一堆神经元并行工作，各自输一个数 → 合起来 = 一层。
- 一层不够就叠更多层，越深越抽象：
  - 浅层认"边缘、颜色" → 中层认"形状" → 深层认"物体"。
- 这就是**深度学习的"深度"**：层层抽象，从简单特征到复杂概念。

## 二、训练三件套（1.5h）★ 核心

> 关键认知：**"学习"这件事 = 不断调旋钮（权重 w），让预测误差变小。** 分三步。

### 2.1 损失（Loss）= "答错罚多少"
- 预测值 a 和真实答案 y 差多少 → 用一个函数算出来，叫损失。
- 损失大 = 答错 = 该罚；损失小 = 答对。
- 常见：均方误差 MSE（回归）、交叉熵（分类）。

### 2.2 梯度下降 = "蒙山下山"
- 想象蒙眼站在山上，目标是谷底（损失最小）。
- 每步朝着"脚下最陡的下坡方向"挪一步：
  ```
  w = w - 学习率 × (dLoss/dw)
  ```
- **学习率 = 步长**：
  - 太大 → 一个台阶跨太大，直接跳过谷底 → 震荡甚至发散。
  - 太小 → 磨磨蹭蹭，很久才到底。

### 2.3 反向传播 = "把锅甩回责任人"
- 输出错了，得知道**每个旋钮**该往哪调。
- 从输出层往回推，用**链式法则**：谁离错误近谁多调，谁贡献小少调。
- 这一步叫"反向传播"（Backpropagation）——误差一层层反向传回去，给每个权重算梯度。

### 2.4 训练循环（4 步转起来）
```
喂数据 → 模型出预测 → 和真值比算损失 → 反向传播算梯度 → 优化器调权重 → 重来
```
转够多轮，权重调到"这条规律"的最优点 → 训练完成，保存这个模型。

## 三、实战：手算一个小神经元（2h）★ 产出①

> 用 numpy 手写一个神经元。给输入、权重，算输出；再走一步梯度下降，看 loss 怎么降。

```python
"""D1-神经元前向传播 + 一次梯度下降 · ML/DL 扫盲"""
import numpy as np

# --- 一个简单神经元 ---
def neuron(inputs, w, b):
    """前向传播：z = Σ(x·w) + b，再经过 ReLU 激活。"""
    z = np.dot(inputs, w) + b
    return np.maximum(0, z)          # ReLU 激活

# 给数据：输入 x，期望输出 y（一条直线 y = 2x）
X = np.array([[1.0], [2.0], [3.0]])
y = np.array([2.0, 4.0, 6.0])

# 初始"瞎设"的旋钮
w = np.array([[0.5]])      # 初始猜测
b = np.array([0.0])

def mse(pred, target):
    """损失：预测和真实的均方误差。"""
    return np.mean((pred - target) ** 2)

lr = 0.1                   # 学习率（步长）
print(f"初始损失: {mse(neuron(X, w, b), y):.4f}")

# 一次梯度下降（示意：用解析梯度 2*(pred-y)*x）
for step in range(3):
    pred = neuron(X, w, b)
    diff = pred - y
    grad_w = (2 * diff * X).mean()   # dLoss/dw 的近似
    grad_b = (2 * diff).mean()       # dLoss/db 的近似
    w -= lr * grad_w                 # 挪旋钮
    b -= lr * grad_b                 # 挪旋钮
    print(f"step{step}  损失: {mse(pred, y):.4f}")

print(f"收敛后 w={w[0][0]:.3f}  b={b[0]:.3f}  (理想 w≈2, b≈0)")
```

**期望现象**：跑完损失一路下降，w 逼近 2、b 逼近 0——这就是"学会了 y=2x"。

## 四、训练 vs 推理（1.5h）★ 概念铺垫

> 今天先埋个概念，下周细讲。一句话区分：

| 维度 | 训练（Train） | 推理（Inference） |
|---|---|---|
| 做什么 | 学规律：算梯度、改权重 | 应用规律：新数据过一遍出结果 |
| 动权重吗 | 动（反复调 w） | 不动（锁定） |
| 速度/开销 | 慢、烧卡 | 快、省钱 |
| 阶段 | 离线开发 | 上线服务 |

> 训练好的模型保存上线，之后只做推理。这就是为什么"模型训练要 GPU"但"线上推理"轻量得多。

## 五、概念笔记① 落盘（1.5h）★ 产出

> 把上面压成记忆点（一句话一个概念）：

1. **神经元** = 加权求和 + 偏置 + 弯折激活。旋钮是权重。
2. **损失** = 预测 vs 真实差多少 → 差=错。
3. **梯度下降** = 蒙眼下山，朝下坡挪旋钮：`w = w - 学习率×dLoss/dw`。
4. **反向传播** = 用链式法则把误差往后推，给每个权重算梯度。
5. **训练循环** = 喂数据→出预测→算损失→反向传播→调权重→重来。
6. **训练 vs 推理** = 训练=学规律（动权重）；推理=应用规律（不动权重）。

## 六、面试口述版（用大白话讲，别背术语）

> 神经网络像一堆叠起来的开关旋钮。旋钮是权重，调得好就能把输入变成对的输出。
> "学习"就是反复试错：先猜一下，跟答案比一比差多少（这叫损失），
> 然后谁责任大就调谁（反向传播），一步步往"更准"的方向挪（梯度下降）。
> 调得差不多了保存起来，上线拿来干正事——那就是"推理"。
