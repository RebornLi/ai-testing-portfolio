## 一、任务完成率：Agent 评测的核心指标（1.5h）★ 今日重点

> 一句话：**工具调用对了，但如果没凑成一个完整任务，照样是失败。**

D2 我们测了"每一步工具对不对"。但真实任务往往是**多步组合**：

- 用户说："帮我算 3+4，然后结果再乘 2，最后告诉我答案"
- Agent 要连续完成：`add(3,4)` → `multiply(7,2)` → 回答
- 只有**全部步骤都到位**，任务才算完成

> **任务完成率 = 实际完成的必要步骤 / 必要的总步骤。**
> 单步工具对了，但漏了最后一步，完成率还是不到 100%。

### 与 D2 评测的关系

| | D2 工具调用评测 | D3 任务完成率 |
|---|---|---|
| 关注点 | 每一步对不对 | 整条链路有没有走全 |
| 粒度 | 单步断言 | 任务级完成率 |
| 反例 | 参数写错 | 漏掉最后一步 |

## 二、任务完成率怎么算（1.5h）★ 核心

> 把任务拆成"必要步骤"，Agent 每完成一个就给分。

```
任务完成率 = 实际完成必要步骤数 / 必要步骤总数 × 100%
```

- 任务 = 一条有目标的步骤链。
- 必要步骤 = 完成这个目标必须做的工具调用（顺序可以微调，但都得有）。
- Agent 的 `trajectory` 里，每个 `tool_call` 算一个步骤，`answer` 也算最后一步。

### 多轮上下文评测：怎么测 Agent 会不会"忘事"

> 多轮对话中，后面的回合要记得前面轮次的信息。
> 设计：第一轮告诉 Agent "我叫小明，喜欢北京"，
> 第三轮问"我刚才说我喜欢哪个城市？"——
> 好 Agent 能从上下文/记忆里找到答案；忘事的 Agent 会答"不知道"。

## 三、带 Memory 的确定性 Agent（2h）★ 产出①

> 在 D2 的 agent 上加 `Memory`，让它能把上下文写进"小本本"，多轮复用。

### 3.1 工具集（复用 D2）

```python
"""工具集：确定性，不依赖真实服务"""
TOOLS = {"add", "multiply", "lookup", "weather"}


def invoke_tool(name, args):
    if name == "add":
        return args["a"] + args["b"]
    if name == "multiply":
        return args["a"] * args["b"]
    if name == "lookup":
        db = {"beijing": "晴天", "atlantis": "未知"}
        return db.get(args.get("city", "未知"))
    if name == "weather":
        return "晴天 25°C"
    raise ValueError(f"未知工具：{name}")
```

### 3.2 Memory（写 / 读 / 清空）

```python
"""Agent 的记忆：简单 dict，支持写-读-清空"""
class Memory:
    def __init__(self):
        self.store = {}

    def write(self, key, value):
        self.store[key] = value
        return True

    def read(self, key):
        return self.store.get(key)

    def clear(self):
        self.store.clear()
        return True
```

### 3.3 带记忆的 Agent

```python
"""带 Memory 的 Agent：多轮对话中记住关键信息"""
from tools import invoke_tool


class ToolCall:
    def __init__(self, name, args, result=None):
        self.name, self.args, self.result = name, args, result


class MemoryAgent:
    def __init__(self, planner, memory=None, max_iterations=10):
        self.planner = planner
        self.memory = memory or Memory()
        self.max_iterations = max_iterations

    def run(self, prompt):
        """跑一轮，返回 {answer, trajectory, reason}。
        规划器能拿到 self.memory 来读写上下文。
        """
        trajectory, state = [], ""
        for _ in range(self.max_iterations):
            decision = self.planner(prompt, trajectory, state, self.memory)
            if "answer" in decision:
                return {"answer": decision["answer"], "trajectory": trajectory,
                        "reason": "stopped"}
            name, args = decision["tool"]
            result = invoke_tool(name, args)
            trajectory.append(ToolCall(name, args, result))
            state += f"\n[{name} {args} -> {result}]"
        return {"answer": None, "trajectory": trajectory, "reason": "max_iterations"}
```

## 四、多轮上下文评测：好 Agent 记住上下文（2h）★ 产出

> 设计三轮对话。第一轮喂信息，第三轮考"还记得吗"。

```python
"""好 Agent：用 memory 记住上下文，第三轮能答对。

关键：只建一个 agent，多轮共用它自己的 memory（跨轮共享）。
每轮跑一次 run()，trajectory 和 memory 在同一 agent 内累积。
"""

class RememberingPlanner:
    """记住第1轮说的内容，第3轮考问时从 memory 读出答案"""
    turn = 1  # 记录当前是第几轮（单 agent 多轮递增）

    def __call__(self, prompt, trajectory, state, memory):
        if self.turn == 1:
            memory.write("user_name", "小明")
            memory.write("favorite_city", "北京")
            self.turn += 1
            return {"answer": "好的，我记住了"}
        if self.turn == 3:
            city = memory.read("favorite_city")     # 从记忆读取，而不是凭空回答
            self.turn += 1
            return {"answer": f"你之前说喜欢{city}" if city else "我不记得"}
        self.turn += 1
        return {"answer": "等待"}

# 只建一个 agent，三轮共用同一份 memory
agent = MemoryAgent(RememberingPlanner())
for turn in (1, 2, 3):
    res = agent.run(f"第{turn}轮提问")
    if turn == 1:
        print(f"[轮{turn}] {res['answer']}  |  记忆: {dict(agent.memory.store)}")
    elif turn == 3:
        print(f"[轮{turn}] 考问: 我喜欢哪个城市? -> {res['answer']}")
        assert "北京" in res["answer"], "好 Agent 应该记得北京"
print("好 Agent 成功记住上下文 ✅")
```

**期望**：第 3 轮答案含"北京"，断言通过。

## 五、多轮上下文评测：坏 Agent 忘事（1.5h）★ 产出

> 设计一个**不用 Memory** 的 Agent：它不写、不读记忆，第三轮必然答不出。

```python
"""坏 Agent：不写记忆，第三轮考不住 -> 暴露'忘事'"""

class ForgettingPlanner:
    """永远不写 memory，所以第三轮考不住"""
    def __call__(self, prompt, trajectory, state, memory):
        # 不写任何记忆
        return {"answer": "抱歉，我不记得"}

# 坏 Agent 从不写记忆，跑完多轮 memory 依然是空的
bad_agent = MemoryAgent(ForgettingPlanner())
print(f"[轮1] {bad_agent.run('第1轮提问')['answer']}  |  记忆空: {dict(bad_agent.memory.store)}")
print(f"[轮3] {bad_agent.run('第3轮提问')['answer']}  |  记忆空: {dict(bad_agent.memory.store)}")

assert dict(bad_agent.memory.store) == {}, "坏 Agent 记忆是空的"
print("坏 Agent 果然忘事 ✅ 评测成功抓住")
```

**观察**：好 Agent 记忆有内容、第3轮答"北京"；坏 Agent 记忆空、答"不记得"。
**评测的价值**：一眼看出谁"忘事"。

## 六、任务完成率评测（1.5h）★ 产出

> 给一个多步任务，算 Agent 完成了百分之多少。

```python
"""任务完成率：算真实完成步骤 / 必要步骤"""
good_plan_steps = ["add", "multiply", "answer"]   # 必要步骤
bad_plan_steps  = ["add", "answer"]                # 漏了 multiply

def completion_rate(steps_executed, necessary):
    done = sum(1 for s in steps_executed if s in necessary)
    return done / len(necessary)

# 好 Agent：add → multiply → answer
good_done = ["add", "multiply", "answer"]
# 坏 Agent：add → answer（漏 multiply）
bad_done = ["add", "answer"]

print(f"好 Agent 完成率: {completion_rate(good_done, good_plan_steps)*100:.0f}%")
print(f"坏 Agent 完成率: {completion_rate(bad_done, good_plan_steps)*100:.0f}%")

assert completion_rate(good_done, good_plan_steps) == 1.0, "好 Agent 应 100%"
assert completion_rate(bad_done, good_plan_steps) < 1.0, "坏 Agent 应 <100%"
print("任务完成率评测能区分好坏 ✅")
```

**期望**：好 Agent 100%，坏 Agent 67%。

## 七、综合评测：给 Agent 打总分（1.5h）★ 产出

> 把"任务完成率" 和 "上下文评测" 合在一起，给一个多轮 Agent 综合打分。

```python
"""综合打分：任务完成率 × 上下文记忆。

关键：多轮共用一个 agent，memory 才轮轮累积留得住。
每新建一个 agent 就各存各的 memory，跨轮就读不到了。
"""

class TaskAgentMemoryPlanner:
    """第1轮写记忆+add，第2轮写记忆+multiply（做完整任务）"""
    turn = 1

    def __call__(self, prompt, trajectory, state, memory):
        if self.turn == 1:
            memory.write("user_name", "小明")
            return {"tool": ("add", {"a": 3, "b": 4})}
        if self.turn == 2:
            memory.write("first_result", "7")
            return {"tool": ("multiply", {"a": 7, "b": 2})}
        return {"answer": "完成"}

# 好 Agent：一个 agent 跑两轮
good_agent = MemoryAgent(TaskAgentMemoryPlanner())
good_agent.run("第1轮")
good_agent.run("第2轮")
good_done = ["add", "multiply"]

score = {
    "任务完成率": completion_rate(good_done, ["add", "multiply"]),
    "上下文记忆": bool(good_agent.memory.read("user_name")),
}
print("综合评分:", score)
print(f"总分: {sum(score.values())/len(score)*100:.0f}%")
assert all(score.values()), "好 Agent 四维度维度都该过"
print("综合评测能区分好坏 Agent ✅")
```

## 八、概念笔记③ 落盘（1.5h）★ 产出

> 一句话记忆点：

1. **任务完成率** = 完成必要步骤 / 必要步骤总数，测整条链路走没走全。
2. **单步对了 ≠ 任务完成**：漏最后一步，完成率仍不到 100%。
3. **多轮上下文**：靠 Memory，把关键信息写进小本本，后续回合复用。
4. **忘事 = 不写记忆**：坏 Agent 不读写 memory，第三轮考不住。
5. **评测区分**：好 Agent 完成率 100%、记忆有内容；坏 Agent 67%、记忆空。
6. **综合打分**：任务完成率 + 上下文记忆，凑成整体评分。

## 九、面试口述版（大白话）

> 给 Agent 打分，就像给学生布置一个综合任务，看两点：
> 第一，整件事做完没有（任务完成率）——每一步都对才叫完成。
> 第二，多轮对话时记不记得前面说过啥（上下文）——好学生会拿小本本记关键信息，
> 忘事的学生的记忆是空的，问一句答一句，根本不记。
> 评测就是把这两种 Agent 放一起跑同一个任务，看谁达标。
