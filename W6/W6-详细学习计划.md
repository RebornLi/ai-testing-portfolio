## 🎯 本周总目标（对标整体规划 W6）

阶段二「AI 核心」第 6 周，从"会造 Agent"进阶到"会评测 Agent"——评测是 AI 测试岗位的核心竞争力：

1. **Agent 评测框架**：四维度（任务规划 / 工具调用 / 多轮上下文 / 记忆管理），每个维度怎么打分
2. **自动评测脚本**：pytest + LLM 断言，给 Agent 轨迹打分、出成功率
3. **成本 & 延迟**：怎么量化"这个 Agent 又快又省"
4. **开源贡献**：给 RAGAS / DeepEval / Dify 提一个真实 issue（从使用者→贡献者）

> ⚠️ 本周要动手搭 `eval-lab/`——不是纸上谈兵，要能跑出分数。

## 📅 每日任务

### D1（09-04 周五）：Agent 评测基础 — 四维度评分框架 ★
- 学习：为什么 Agent 评测比"问答对错"难？工具调用链路、轨迹、状态如何打分
- 实战：给一个"确定性 Agent"跑一个任务，手算四个维度的得分
- 产出：概念笔记① 评测四维度表 + 一句话笔记
- 验收：能讲清"怎么评价一个 Agent 做得好不好"

### D2（09-05 周六）：工具调用维度评测 ★
- 学习：怎么断言"工具调对了"——参数、参数名、调用顺序、边界
- 实战：用 W4 的确定性 ReAct Agent，写一组工具调用断言用例
- 产出：评测用例集（工具调用维度）+ 测试报告
- 验收：能写出 5 条"工具调用是否正确"的断言

### D3（09-06 周日）：任务规划 & 多轮上下文评测 ★
- 学习：任务完成率、规划步骤是否合理、多轮对话是否记住上下文
- 实战：设计多轮任务，测 Agent 是否"忘事"
- 产出：任务完成率评测脚本 + 多轮上下文测试
- 验收：能设计"任务失败"的用例并检测出来

### D4（09-07 周一）：成本 & 延迟评测 ★
- 学习：怎么量化 Agent 的成本（token 数、API 调用次数）和延迟（每步耗时、总耗时）
- 实战：给 Agent 加计时 + token 计数，算"成功率 vs 成本"的平衡
- 产出：成本/延迟评测脚本（含可视化）
- 验收：能算出"完成任务的边际成本"

### D5（09-08 周二）：DeepEval 框架 & 自动化评测 ★
- 学习：DeepEval 是什么、怎么接 pytest、`TestCase` 怎么写断言
- 实战：用一个真实 LLM API（本地 :8000 或 mock），写 DeepEval 测试
- 产出：`eval-lab/` 自动化评测脚本（DeepEval + pytest）
- 验收：能跑通一次 DeepEval 测试并出分数

### D6（09-09 周三）：本周里程碑 + 开源贡献
- 任务：写 `W6-milestones-Agent评测.md`（四维度评测 + 自动化脚本 + 贡献）
- 开源：给 RAGAS / DeepEval / Dify 提一个真实 issue（描述 bug 或功能建议）
- 复盘：完成度自评、卡点、W7 预习（框架工程化）
- 验收：一套完整的 Agent 评测方案 + 一个开源 issue 链接 + commit
