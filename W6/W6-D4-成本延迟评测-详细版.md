## 一、为什么成本 & 延迟也是评测维度（1.5h）★ 今日重点

> 一句话：**答案对了，但烧了一万块、等了 5 分钟，这个 Agent 上线也是不合格的。**

AI 评测不能只看"对不对"。真实上线有三个硬约束：

| 约束 | 是什么 | 为什么重要 |
|---|---|---|
| **成本** | 每次 API 调用烧多少钱 | 调用越多越贵，用户等不起钱 |
| **延迟** | 一次回答要多快返回 | 用户耐心只有几秒 |
| **成功率** | 答案对不对 | 这个最基础 |

> 好 Agent 要三者兼得：**答得对、花得少、回得快。**
> 评测就是要同时量这三个数，看 Agent 在哪个维度拉胯。

## 二、成本怎么算（1.5h）★ 核心

> 真实 LLM 按"调用次数 × token 数 × 单价"收费。没有真实模型时，用**工具调用次数**当代理指标。

### 成本公式
```
总成本 = Σ(每次工具调用的 token数) × 单价
近似 = 工具调用次数 × 每次平均token × 单价
```

### 三个可量化指标

| 指标 | 含义 | 怎么量 |
|---|---|---|
| **工具调用次数** | Agent 干了多少活 | 数 trajectory 里的 tool_call |
| **每步耗时** | 每个工具多快 | 包裹工具计时 |
| **总耗时** | 整个任务多久 | run 前后打时间戳 |
| **总成本** | 花了多少钱 | 调用次数 × 单价 |

> **边际成本**：每多完成一个任务，要多花多少钱。这是评估"能不能规模化"的关键。

## 三、带计时的 Agent（2h）★ 产出①

> 在 agent 外面包一层"计时器 + 计数器"，不改动 agent 本身。这是评测的关键：**把 agent 当黑盒，从外面量它。**

### 3.1 工具集（复用）+ 单价

```python
"""工具集：确定性 + 每个工具的价格（单位：元/次）"""
TOOLS = {"add", "multiply", "lookup", "weather"}
PRICES = {"add": 0.001, "multiply": 0.001, "lookup": 0.002, "weather": 0.002}


def invoke_tool(name, args):
    if name == "add":
        return args["a"] + args["b"]
    if name == "multiply":
        return args["a"] * args["b"]
    if name == "lookup":
        db = {"beijing": "晴天", "atlantis": "未知"}
        return db.get(args.get("city", "未知"))
    if name == "weather":
        return "晴天 25°C"
    raise ValueError(f"未知工具：{name}")
```

### 3.2 计时包装器：记录每次工具调用花了多久

```python
"""计时工具：包裹一个函数，记录它的耗时"""
import time


class Timer:
    """测一段代码跑多久。用法：with Timer() as t: ...  然后 t.elapsed 就是秒数。"""
    def __init__(self):
        self.elapsed = 0.0

    def __enter__(self):
        self.start = time.time()
        return self

    def __exit__(self, *args):
        self.elapsed = time.time() - self.start


class CostTracker:
    """给工具调用计次数、算成本。"""
    def __init__(self):
        self.count = 0
        self.cost = 0.0
        self.per_step = []      # 每步耗时列表

    def record(self, name, elapsed):
        self.count += 1
        self.cost += PRICES.get(name, 0.001)
        self.per_step.append({"step": self.count, "tool": name, "耗时": round(elapsed, 4)})
```

### 3.3 带成本追踪的 Agent

```python
"""带成本追踪的 Agent：跑一次任务，统计全部开销"""
from tools import invoke_tool


class ToolCall:
    def __init__(self, name, args, result=None):
        self.name, self.args, self.result = name, args, result


class TrackingAgent:
    def __init__(self, planner, tracker=None, max_iterations=10):
        self.planner, self.tracker, self.max_iterations = planner, tracker, max_iterations

    def run(self, prompt):
        tracker = self.tracker or CostTracker()
        answer, reason = None, "max_iterations"
        with Timer() as total:
            trajectory, state = [], ""
            for _ in range(self.max_iterations):
                decision = self.planner(trajectory, state)
                if "answer" in decision:
                    answer = decision["answer"]
                    reason = "stopped"
                    break          # 用 break 而不是 return，让 with 正常退出
                name, args = decision["tool"]
                with Timer() as t:
                    result = invoke_tool(name, args)
                trajectory.append(ToolCall(name, args, result))
                tracker.record(name, t.elapsed)
                state += f"\n[{name} {args} -> {result}]"
        tracker.total_elapsed = total.elapsed   # with 退出后一定执行（修提前 return 绕过）
        return {"answer": answer, "trajectory": trajectory,
                "reason": reason, "tracker": tracker}
```

## 四、跑一次任务看成本（2h）★ 产出

```python
"""跑一个任务，看它花了多少时间、多少钱、干了多少活"""
from tools import invoke_tool


class DeterministicPlanner:
    def __init__(self, steps):
        self.steps, self.i = list(steps), 0

    def __call__(self, trajectory, state):
        if self.i >= len(self.steps):
            raise StopIteration
        kind, *rest = self.steps[self.i]
        self.i += 1
        if kind == "tool":
            return {"tool": (rest[0], rest[1])}
        return {"answer": rest[0]}


tracker = CostTracker()
plan = DeterministicPlanner([
    ("tool", "add", {"a": 3, "b": 4}),
    ("tool", "multiply", {"a": 7, "b": 2}),
    ("answer", "结果是14"),
])
agent = TrackingAgent(plan, tracker=tracker)
res = agent.run("完成任务")

tr = res["tracker"]
print(f"工具调用次数: {tr.count}")
print(f"总成本（元）: {tr.cost:.4f}")
print(f"总耗时（秒）: {tr.total_elapsed:.4f}")
print("每步耗时:")
for s in tr.per_step:
    print(f"  #{s['step']} {s['tool']}: {s['耗时']}s")

# 边际成本：每多完成一个任务要花多少钱
print(f"\n边际成本（每个任务）: ¥{tr.cost:.4f}")
assert tr.count == 2, "应调用了 2 次工具"
assert abs(tr.cost - 0.002) < 1e-9, "2 次工具 × 0.001 = 0.002"
print("成本统计正确 ✅")
```

**期望**：2 次调用、成本 0.002 元、每步有耗时。

## 五、慢 Agent vs 快 Agent（1.5h）★ 产出

> 用 `time.sleep` 模拟真实延迟。慢 Agent 每次都"卡顿"，看延迟怎么累积。

```python
"""慢 Agent（每步 sleep 0.1s）vs 快 Agent（瞬时），比较延迟"""
import time
from tools import invoke_tool


class SlowPlanner:
    """慢规划器：每步故意卡 0.1 秒（模拟真实延迟）"""
    def __init__(self, steps):
        self.steps, self.i = list(steps), 0
    def __call__(self, trajectory, state):
        if self.i >= len(self.steps):
            raise StopIteration
        kind, *rest = self.steps[self.i]
        self.i += 1
        if kind == "tool":
            time.sleep(0.1)
            return {"tool": (rest[0], rest[1])}
        return {"answer": rest[0]}


def measure(name, planner):
    tr = CostTracker()
    res = TrackingAgent(planner, tracker=tr).run("完成任务")
    return tr


fast = measure("快", DeterministicPlanner([
    ("tool", "add", {"a": 1, "b": 1}),
    ("answer", "2"),
]))
slow = measure("慢", SlowPlanner([
    ("tool", "add", {"a": 1, "b": 1}),
    ("answer", "2"),
]))

print(f"快 Agent: 耗时 {fast.total_elapsed:.3f}s, 成本 ¥{fast.cost:.4f}")
print(f"慢 Agent: 耗时 {slow.total_elapsed:.3f}s, 成本 ¥{slow.cost:.4f}")
assert slow.total_elapsed > fast.total_elapsed * 2, "慢 Agent 应该慢很多"
assert slow.cost == fast.cost, "延迟不影响成本（成本只跟调用次数有关）"
print("延迟评测能区分快慢 Agent ✅")
```

**观察**：慢 Agent 耗时约为快 Agent 的 100+ 倍（多睡了 0.1s）；成本一样（都只调用 1 次）。
**关键认知**：**延迟和成本是两码事**——慢不一定贵，调用多才贵。

"""可视化：每个 Agent 在(延迟, 成本)图上的落点"""
import matplotlib.pyplot as plt


def make_agent(speed):
    # P 在闭包裡锁定 speed，__init__ 不需要 pl 参数
    class P:
        def __init__(self): self.steps, self.i = [speed], 0
        def __call__(self, trajectory, state):
            if self.i >= len(self.steps): raise StopIteration
            self.i += 1
            if speed == "slow": time.sleep(0.1)
            elif speed == "medium": time.sleep(0.02)
            return {"answer": f"{speed}结果"}
    return P()


speeds = {"快": "fast", "中": "medium", "慢": "slow"}
points, labels = [], []
for label, spd in speeds.items():
    tr = measure(label, make_agent(spd))
    points.append([tr.total_elapsed, tr.cost])

import numpy as np
arr = np.array(points)
plt.figure(figsize=(6, 4))
for i, lbl in enumerate(labels):
    plt.scatter(arr[i, 0], arr[i, 1], label=lbl, s=100)
    plt.annotate(lbl, (arr[i, 0], arr[i, 1]), textcoords="offset points", xytext=(8, 8))

plt.ylabel("成本（元）")

## 七、综合评测：成功率 × 成本 × 延迟（1.5h）★ 产出

> 给一个打分公式，把三个维度合成一个"Agent 质量分"。

```python
"""综合质量分 = 成功率 × (1 - 成本归一化) × (1 - 延迟归一化)"""


def quality_score(success_rate, cost, latency, max_cost, max_latency):
    cost_norm = min(cost / max_cost, 1.0)   # 成本越接近 0 越好
    latency_norm = min(latency / max_latency, 1.0)
    return success_rate * (1 - cost_norm) * (1 - latency_norm)


# 三个 Agent：快省准 / 慢贵准 / 错得便宜
agents = {
    "快省准": dict(success=1.0, cost=0.001, latency=0.02),
    "慢贵准": dict(success=1.0, cost=0.002, latency=0.15),
    "错便宜": dict(success=0.0, cost=0.0005, latency=0.01),
}
max_cost = max(a["cost"] for a in agents.values())
max_latency = max(a["latency"] for a in agents.values())

print("Agent 质量分（满分 1.0）：")
for name, a in agents.items():
    q = quality_score(a["success"], a["cost"], a["latency"], max_cost, max_latency)
    print(f"  {name}: {q:.3f}  (成功率{a['success']}, 成本¥{a['cost']}, 延迟{a['latency']}s)")

assert agents["快省准"]["success"] == 1.0
print("质量分把三个维度合成一个数，能排序好坏 ✅")
```

**期望**：快省准最高，错最低（成功率 0 拉垮一切）。

## 八、概念笔记④ 落盘（1.5h）★ 产出

> 一句话记忆点：

1. **Agent 评测要量三个数**：成功率（对不对）、成本（贵不贵）、延迟（快不快）。
2. **成本 ≈ 调用次数 × 单价**：调用越多越贵（真实按 token 计费）。
3. **延迟 ≠ 成本**：慢不一定贵，慢只是等得久。
4. **边际成本**：每多跑一个任务多花多少钱，决定能不能规模化。
5. **可视化**：延迟×成本散点图，右下角的点最优。
6. **质量分**：成功率 × (1-成本归一化) × (1-延迟归一化)，三个维度合成一个数。

## 九、面试口述版（大白话）

> 给 Agent 打分不能只看答案对不对，还要看它"烧不烧钱"和"快不快"。
> 就像打车：目的地对了，但绕路半小时、油费翻倍，还是不划算。
> 所以我量三个数——答案对不对、花多少钱、用多久。
> 一个又对又快又便宜的 Agent 才是好 Agent。
